# 원본 측정 자료 보존

사용자의 2026-11-24 요청에 따라 원본도 이 GitHub 저장소에서 보관합니다. 세션별 ZIP은 원본 파일의 내용을 바꾸지 않으며, 파일명·시각·실패/중단 상태도 원본 그대로입니다. `index.json`에는 세션과 스냅샷, 원래 작업 폴더, ZIP과 개별 파일의 SHA-256을 기록합니다.

최초 전체 보관: **28개 세션 · 30개 스냅샷 · 원본 파일 200개**, ZIP 합계 95,394,678바이트(약 91MiB)입니다. 아이패드의 196개 원본 파일 전부와 맥북에 남아 있던 과거 진행 단계 사본을 포함합니다. 각 ZIP과 내부 파일의 해시를 검증했습니다. 이후 추가 분량의 기준은 `index.json`입니다.

같은 세션의 동일 사본은 중복 보관하지 않습니다. 같은 세션 번호라도 진행 중/완료 후 등 내용이 달라진 사본은 서로 다른 ZIP으로 모두 남깁니다. 이전 ZIP을 교체하지 않습니다. 학습 가능 여부는 manifest와 품질 검사로 별도 판단합니다.

ZIP을 풀면 `MagAir-…/manifest.json`, 센서 CSV와 해당 세션 설명 파일이 복원됩니다. 본문 파일은 실제 원본과 바이트 단위로 비교했고, 새 회차도 동일한 방식으로 보관합니다. 분석 결과·빌드·인증 파일은 포함하지 않습니다. 기기나 작업 폴더의 원본도 삭제하지 않았습니다.

## 복원

`index.json`에서 사용할 완료 세션과 ZIP을 선택합니다. 셸에서 예를 들어 아래와 같이 압축을 풀고, 각 파일의 SHA-256을 목록과 비교합니다. 동일 세션의 여러 스냅샷을 한 폴더에 덮어 풀지 마세요.

```sh
unzip datasets/raw/SESSION/SNAPSHOT.zip -d research/data/restored
```

추가 자료를 가져온 뒤 `research/`에서 다음 명령으로 ZIP과 목록을 갱신합니다. 기존 ZIP 내용이 다르면 중단하며, 생성된 ZIP과 `index.json`을 커밋합니다.

```sh
python3 scripts/archive_raw_sessions.py
```

원본에는 실험 시간, 기기 모델, 배치 메모, 센서 시계열이 포함됩니다. 이 경로는 사용자가 지정한 GitHub 저장소의 공개 범위를 따릅니다. `.gitignore`의 `data/` 제외는 작업 사본에만 적용되고, 이 `datasets/` 경로는 추적합니다.
