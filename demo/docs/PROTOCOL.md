# 첫 실험의 정의와 데이터 해석

## 1.5의 현재 실험: 한 변씩 수집

현재 권장 절차는 README의 ‘한 변씩 수집 1.5’입니다. 아래 격자·전체 테두리는 이전 실험의 정의로 보존합니다.

- 한 변 학습: 시작 배경 10초 → 0/25/50/75/100% 5점 정지 3초씩 정방향·역방향 각 1회 → 자유 속도 왕복 3회 → 종료 배경 10초. 각 항목마다 준비 3초이며, 다음 항목은 직접 시작합니다.
- 한 변 검증: 별도 세션, 50/0/75/25/100% 정지 후 보통·느림·중간 정지 왕복 각 1회. 검증 자료를 학습에 합치지 않습니다.
- 위·아래 / 네 변 구분: 각 위치와 왕복 조건별로 변을 교대로 측정합니다. 예측기에 정답 변을 주지 않고 평가합니다. 공유 꼭짓점은 변 분류 평가에서 제외합니다.
- 자세 영향: 위쪽 변 0/50/100%에서 기울기·축 회전을 각각 검사합니다. 펜 끝 고정, 수직 기준 3초 → 변경 4초 → 복귀 3초. 각도는 미측정입니다.
- 왕복 완료 버튼은 출발점으로 돌아온 후 누릅니다. 이동 중 x/y는 비어 있으며 `known_edge_only` 라벨입니다. 시간·자기장 곡선 길이로 실제 위치를 생성하지 않습니다. 3분 초과는 중단 처리합니다.
- 묶음의 마지막 배경 측정이 끝나면 자동 저장·종료합니다. 앱을 배경으로 보내면 중단 상태로 저장되므로 수집 중 앱을 유지합니다.
- `trial.spec`의 edge/scenarioID/edgeAction/purpose를 manifest에 보존합니다. CSV dataset은 edge_train/edge_test/edge_pose/edge_baseline입니다. 원시 신호는 변경하지 않습니다.

분석은 `scripts/build_edge_model.py`를 사용합니다. 같은 조건의 여러 완료 세션을 받아 각 변의 가장 최근 학습으로 곡선을 만들고, 별도 검증 전체 trial을 평가합니다. 시작·종료 배경 간 선형 드리프트 보정은 추정이며 중간 배경 변화의 정답이 아닙니다. 자세 검사는 위치 모델 학습에서 제외합니다. 임의의 mm 정확도, 실제 펜 IMU, 접촉 감지, 내부 보간 정확도를 주장하지 않습니다.

## 검증할 가설

고정된 iPad와 펜 자세, 동일한 책상 평면에서 관찰되는 3축 자기장으로 임계 영역 내 2차원 위치를 구별할 수 있는가? 범위가 작고 민감하다는 관찰만으로 역함수가 유일하거나 필기를 복원할 수 있다고 가정하지 않습니다.

독립 변수는 정규화된 펜 끝 좌표 `(x,y)`이며 펜 높이·기울기·축 회전·iPad 배치·주변 자성체는 통제합니다. 초기 실험은 ‘책상 표면에 접촉하는 제한된 2D 입력’입니다. 자유로운 3D 에어라이팅과 구별해서 보고합니다.

## 위치 표식

사용자가 직사각형을 내려다본 방향을 기준으로 합니다.

```text
사용자에게서 먼 쪽
(0,0) ──→ +x ── (1,0)
  │                 │
  ↓ +y              │
(0,1) ───────── (1,1)
사용자 쪽
```

학습 좌표는 x,y 각각 `{0, 0.25, 0.5, 0.75, 1}`입니다. 검증 좌표는 각각 `{0.125, 0.375, 0.625, 0.875}`입니다. 기본 비율은 사용자가 확인한 가로 1.5 : 세로 1이며 설정에서 바꿀 수 있습니다. 비율은 그림을 위한 근사치입니다. 물리적 거리 오차는 나중에 실제 가로·세로 길이를 측정한 후 환산합니다.

센서 Bx/By/Bz는 iPad 하드웨어 좌표이며 화면이나 책상 좌표로 회전시키지 않습니다. iPad를 움직이거나 돌리면 새 실험 배치이므로 새 세션이 필요합니다.

| 공중 테두리 | 약 1cm 위에서 시계·반시계 각각 12초 × 5회 | 접촉 경로와 공중 경로의 신호 탐색 |

| 들기/내리기 | 중앙에서 접촉 3초·들기 3초 × 5회 | 높이 변화와 위치 변화의 혼동 |
| 축 회전 | 중앙에서 12초마다 천천히 돌렸다 복귀 × 5회 | 작은 자세 차이의 영향 |
| 자유 궤적 | 30초 | 탐색용; 정답 위치 없음 |
| 종료 배경 | 펜을 멀리 둔 10초 | 배경 드리프트 |

추가 블록은 선택입니다. 자가 없는 초기 최소 데이터는 시작 배경, 네 모서리 3회, 종료 배경입니다. 테두리와 대각선을 이어서 수집하면 다음 단계에 도움이 됩니다. 이 단계에는 격자나 중앙 표식이 필요 없습니다. 내부 좌표 보간을 정량 평가하려면 이후 학습 격자 3회와 검증 격자 2회를 수집합니다. 들기와 축 회전은 자세 고정 가정을 일부러 깨는 별도 실험이므로 위치 모델 학습에 섞지 않습니다. 축 회전각·높이 정답은 측정하지 않으므로 설정 메모에 대략적인 동작 범위를 기록하세요.

네 모서리 블록은 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래 순서로 고정합니다. 동일 순서라는 제약을 보고하고 시간·순서 일반화를 주장하지 않습니다. 첫 두 회차의 각 모서리 자기장 중앙값을 기준으로 세 번째 회차를 최근접 모서리에 분류합니다. 소수의 정지점 확인이며 내부 좌표 모델을 학습하지 않습니다. 모서리는 별도의 `corner_pilot` 데이터셋으로 저장해 정밀 격자 학습에 섞지 않습니다.

## 높이 비교의 정의

높이는 책상 평면에서 펜 끝까지입니다. 첫 안내 높이는 약 1cm(명목 10mm)이며 최적 감지 높이라고 가정하지 않습니다. 눈대중이므로 실제 높이와 다른 수 있으며, 기울기·축 회전·XY 위치는 최대한 유지합니다. 높이를 올리는 별도 프로토콜이 일반 설정의 ‘책상 접촉’ 조건을 의도적으로 바꿉니다. 세션 전체가 같은 높이였다고 해석하면 안 됩니다.

`cornersHeight`는 모서리마다 준비 3초 후 다음 순서로 13초 기록합니다.

| 경과 시간(준비 후) | phase | 동작 | 안내 높이 |
|---|---|---|---|
| 0–3초 | surface_hold | 책상에 가볍게 접촉하고 정지 | 0mm |
| 3–5초 | lift_transition | 같은 위치에서 수직으로 들어 올리기 | 없음 |
| 5–8초 | air_hold | 약 1cm 위에서 정지 | 10mm |
| 8–10초 | lower_transition | 같은 위치로 내려놓기 | 없음 |
| 10–13초 | surface_return | 다시 접촉하고 정지 | 0mm |

네 모서리 순서는 기본 모서리 측정과 같고 세 번 반복합니다. `height_paired` 데이터셋, `manual_height_instruction` 레이블이며 2D 좌표 학습에 섞지 않습니다. `TrialSpec.nominalLiftMM`과 CSV의 `instructed_tip_height_mm`는 안내값이며, `height_label_source=operator_instruction_unmeasured`로 기록합니다. 접촉 여부를 직접 관측하지 않습니다. 이동 전환에는 높이값을 붙이지 않습니다. `clockwiseAir`/`counterclockwiseAir`는 `trajectory_air`, 좌표는 여전히 `guide_only`입니다.

분석은 각 정지 구간 처음 0.4초·마지막 0.2초를 제외합니다. 세 구간 모두 10샘플 이상, 유효 시간폭 1.5초 이상, 최대 공백 0.5초 이하인 완료 trial만 비교합니다. 3축 중앙값으로 공중–접촉(들기 전·내린 후의 평균)의 벡터 차이와 거리를 계산하고, 접촉 전후의 차이도 함께 보고합니다. 높이 효과와 재배치 오차·자세 변화가 혼재할 수 있으므로 이를 접촉 분류 정확도 또는 높이 오차로 보고하지 않습니다. 공중 테두리는 손의 속도와 경로·높이 정답이 없어 접촉 경로와 샘플 단위로 대응시킨 정량 오차를 계산하지 않습니다.

## 시간과 정답 레이블

각 trial에 3초의 `settle` 구간이 있습니다. 정지점 측정은 그 다음 `hold` 구간 3초입니다. 시작 버튼을 누르는 손 때문에 iPad가 흔들릴 수 있어 준비 구간을 분석에서 제외합니다. 준비 3초가 지나도 기기가 흔들렸다면 재측정하세요.

타임스탬프는 Core Motion이 제공한 기기 부팅 기준 시간입니다. UI 콜백 수신 시간으로 덮어쓰지 않습니다. `received_uptime_s`도 별도로 보존해 전달 지연을 확인할 수 있습니다. 절대 시각은 세션 시작 시의 uptime/Unix 앵커를 이용한 근사 변환입니다.

정지점의 `manual_static_target`은 사람이 표식에 맞춘 **근사 정답**입니다. 실제 위치·90°·로고 방향을 외부 장비로 측정하지 않습니다. 화면의 움직이는 안내점은 `guide_only`이며 실제 펜 끝 좌표가 아닙니다. 사용자의 속도·반응 지연이 있으므로 시간 비례로 실제 위치라고 간주하면 안 됩니다. 향후 궤적 오차를 수치화하려면 위쪽 카메라 등 독립적인 위치 기준과 시간 동기화가 필요합니다.

## 저장과 무효 처리

기록 중 모든 센서 스트림을 독립적으로 저장합니다. trial 사이 데이터는 `idle`이며 학습 정답으로 사용하지 않습니다. 원시 센서의 DC 오프셋과 3축 값은 그대로 유지합니다. 기기 자세는 자기 북쪽 보정을 사용하지 않는 `xArbitraryZVertical`입니다. 저장된 quaternion은 펜의 자세가 아닙니다.

`pencil_events.csv`는 앱 화면에서 실제로 수신한 접촉·호버만 기록합니다. 책상 영역에서는 비어 있을 수 있고 이는 정상입니다. Pencil 2세대의 축 회전각은 지원되지 않아 빈칸으로 저장합니다. `altitude_rad`는 책상이 아닌 화면 평면 기준입니다. 호버의 timestamp는 수신 시간이고 정밀한 하드웨어 타임스탬프가 아닙니다. 화면을 떠난 뒤 자세 값을 유지하거나 보간해서 책상 자세로 사용하면 안 됩니다. 책상에서의 미세 기울기·회전을 정량적으로 보정하려면 독립 카메라 관측이나 다른 외부 기준이 추가로 필요합니다. 초기에는 자세를 최대한 고정하고 반복 측정에서 생기는 차이를 오차로 평가합니다.

중단 trial은 `aborted`, 직전 재측정으로 대체된 trial은 `invalidated`입니다. 강제 종료 후 마지막 상태가 `recording`인 trial도 제외합니다. manifest와 CSV를 함께 전달해야 이 상태를 올바르게 반영할 수 있습니다. 완료된 구간은 원본을 덮어쓰지 않습니다.

## 1차 분석에서 볼 내용

1. 실측 Hz, 간격 분포, 긴 데이터 공백, 누락/중복 타임스탬프를 확인합니다.
2. 같은 지점 반복의 자기장 분산과 서로 다른 지점의 자기장 거리를 비교합니다.
3. 학습 1·2회차 → 3회차 검증으로 시간·재배치 오차를 살펴봅니다.
4. 학습 25점 → 별도 16점으로 새로운 위치 보간 성능을 평가합니다.
5. 시작/종료 배경 차이와 iPad IMU 경고가 있는 구간을 검토합니다.
6. 그 후 동적 궤적 추정과 지연·부드러움을 살펴봅니다. 동적 안내 경로를 정답으로 둔 정확도 수치는 계산하지 않습니다.

먼저 단순 kNN 기준 모델을 사용합니다. 실제 데이터의 자기장 분포에 따라 RBF, Gaussian Process, 작은 회귀 모델 등의 대안을 비교할 수 있습니다. 새 모델 선택에 검증점을 반복 사용하면 최종 평가가 낙관적이 되므로 이후 별도 최종 테스트 세션을 수집합니다. 동일 세션 결과를 다른 사용자·다른 날·다른 펜 자세로 일반화하지 않습니다.

## 실기기 첫 확인

- 펜을 치운 상태와 임계 영역 안 상태에서 Bx/By/Bz가 다르게 변하는지 확인합니다.
- 배경 10초와 정지점 하나를 저장해 ZIP에 다섯 CSV와 manifest가 들어 있는지 확인합니다. Pencil 이벤트 파일은 헤더만 있을 수 있습니다.
- 자력계 값이 일정하게 잘리거나 평평해지면 포화/클리핑 가능성을 원시 값으로 검토합니다. 지원 센서 범위를 미리 가정하지 않습니다.
- 고정 배치 사진 또는 간단한 배치 설명을 ZIP과 함께 보내면 좌표 방향과 환경 재현에 도움이 됩니다.
