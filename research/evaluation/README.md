## 왜 평가로 부를 수 있는가

**시험 후 학습(test-then-train)**의 회차 단위 적용입니다. 예측·평가 시점에 모델이 그 회차를 학습하지 않았다면 이후 그 자료를 다음 모델의 학습에 쓰더라도 과거 평가가 소급해서 무효가 되지는 않습니다. [River의 progressive validation 설명](https://riverml.xyz/dev/api/evaluate/progressive-val-score/)과 같은 순서를 회차 전체에 적용합니다. 이 프로젝트는 스트리밍 온라인 학습 알고리즘을 사용한다는 뜻은 아닙니다.

이름은 **회차 간 사전 평가 / 반복 배치 일반화**로 합니다. 재현율(recall)은 분류 지표이므로 위치 추정의 주 지표로 쓰지 않습니다. 오차는 인쇄 목표 좌표와의 2차원 유클리드 거리(mm)입니다. [회귀 평가 지표 안내](https://scikit-learn.org/stable/modules/model_evaluation.html#regression-metrics)에 따라 평균·중앙값·RMSE를 기록하고 큰 오차를 보기 위해 95백분위도 기록합니다.

## 고정된 평가 기준

- [plan.json](plan.json)에 사용 조건·단계·2.5/5mm 기준·1회차 원본 해시를 고정했습니다. [frozen/pass1.json](frozen/pass1.json)은 평가 전의 1회차 모델입니다. SHA-256: `2822aa5a099f18ad70eec08266a473f145a331a0edb1a54d57f1997dc2c8a509`.
- 기본 평가는 각 점의 정지 구간 앞 0.4초/뒤 0.2초를 제외한 **3축 중앙값 − 그 행의 시작 배경**으로 추정합니다. 273개 위치를 같은 가중치로 셉니다. 이는 정지점 대표값 평가이며 실시간 한 프레임 정확도는 아닙니다.
- 별도로 점당 3개의 인과적 0.12초 필터 재생 결과를 기록합니다. 819프레임은 독립적으로 819번 다시 놓은 실험이 아닙니다.
- 위치 목표·행/열·안내선·이동 시간은 추정 입력으로 제공하지 않습니다. 종료 배경은 주 평가에 쓰지 않고, 종료 배경까지 사용한 오프라인 보정은 별도 진단으로 구분합니다.
- 중앙/95% 오차는 **표시를 거부한 후보까지 포함한 전체 후보 오차**입니다. 정상 표시율은 앱의 청록색 표시 기준을 통과한 비율입니다. 주황색/미표시도 포함하는 후보 표시율과 정상 표시된 점만의 오차는 상세 결과에 별도로 남깁니다.
- 2.5mm/5mm 이내 성공률은 **정상 표시되고 해당 거리 이내인 점 수 / 전체 273점**입니다. 표시가 안 된 점을 빼서 점수를 높이지 않습니다.
- 모든 13행의 품질을 검사합니다. 미완료/센서 공백/측정 중 기기 움직임 등이 있으면 완전한 평가·병합을 중단합니다. 사유를 기록한 재수집이나 명시적 검토 없이 조용히 제외하지 않습니다.
- 평가 회차가 학습 세션에 포함됐거나, 앱이 기록한 평가 모델 해시/학습 회차가 다르면 거부합니다. 원래 학습 자료가 고정 모델을 재생성하는지도 확인합니다.
- 2회차 평가가 저장된 다음에만 1+2회차 모델을 생성합니다. 3회차 수집은 1+2회차 모델이 앱에 적용되어야 시작할 수 있습니다.

이 평가는 **이미 학습한 273개 좌표에 다시 놓았을 때**의 성능입니다. 새 공간 위치·연속 필기·새 자세의 정확도를 입증하지 않습니다. 2회차부터 수집 시간이 바뀌므로 회차별 차이가 학습량 증가 때문만이라고 해석하지 않습니다. 평가 결과를 보고 알고리즘이나 임계값을 반복 조정했다면 그 사실도 기록합니다. 전체 3회차 모델은 별도 평가가 없다는 한계를 유지합니다.

## 다음 회차 완료 후 실행

`research/`에서 실행합니다. 아래의 `PASS2`는 실제 자료를 가져온 경로로 바꿉니다. 검토 옵션은 기존 1회차의 이동/준비 구간 경고를 명시적으로 검토한 사유이며 실제 측정 중 움직임을 허용하지 않습니다. 새 회차의 경고도 먼저 확인해야 합니다.

```sh
python3 scripts/evaluate_printed_pass.py \
  --model evaluation/frozen/pass1.json \
  --training-sessions data/printed-grid-20261123-pass1/MagAir-*/ \
  --evaluation-sessions data/PASS2/MagAir-*/ \
  --test-pass 2 --out reports/pass1-to-pass2 \
  --allow-reviewed-transient-motion \
  --review-note 'Record the actual reviewed non-measurement motion here.'
```

출력은 고정 모델 사본, `evaluation.json`, 점별 예측, 원본 해시, `next_model.json`, 표에 붙일 `ledger_row.md`입니다. 결과 폴더는 덮어쓰지 않습니다. 다음 모델을 앱에 적용하기 전에 평가 요약을 표에 남기고 모델 사본을 `evaluation/frozen/`에 고정합니다. 같은 방식으로 1+2회차 모델과 3회차 자료를 평가합니다.
