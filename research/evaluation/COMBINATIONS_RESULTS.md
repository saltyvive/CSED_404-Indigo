## 평가를 구분하는 기준

- 먼저 수집 전에 고정한 A12/B12로 3회차를 평가·저장한 뒤 A123/B123을 만들었습니다. 3회차의 13개 manifest에 A12/B12 해시가 일치합니다.
- 이후 사용자 요청으로 `1, 2, 3, 12, 23, 13, 123`을 모두 만들었습니다. A/B의 알고리즘·임계값은 그대로이며 점수를 보고 튜닝하지 않았습니다. 나머지 비교는 **사후 회차 분리 재생 평가**입니다.
- 각 모델을 세 회차 모두에서 재생했습니다. 학습에 포함한 회차는 `training_replay`, 포함하지 않은 회차는 `held_out_pass`로 분리합니다. 123에는 후자가 없습니다.
- 주 지표는 각 정지점의 앞 0.4초·뒤 0.2초를 제외한 자력계 중앙값에서 **해당 행 시작 배경만** 뺀 입력입니다. 273점을 같은 가중치로 평가합니다. 종료 배경은 학습 보정과 별도 진단에만 사용합니다.
- 중앙/P95 오차는 거부된 후보까지 포함한 2D 위치 오차(mm)입니다. 성공률은 **정상 표시되고 2.5 또는 5mm 이내인 점 / 전체 273점**입니다. 정상 표시율은 청록색 판정을 받은 비율이고, 주황색 후보를 포함한 후보 표시율은 이번 모든 조합·회차에서 100%였습니다.
- 이를 '위치 재현 성공률'로 읽을 수 있지만 분류 지표 recall은 아닙니다. 별도 0.12초 인과적 필터 재생은 점당 3프레임이며 서로 독립된 819번의 배치가 아닙니다.

## 학습량 증가 효과

시험 회차를 하나씩 제외하고 나머지 단일 회차 두 모델의 결과를 합친 값과, 두 회차를 함께 학습한 모델을 비교합니다. 각 시험 회차의 가중치는 동일합니다. 단일 회차 쪽 1,638개 예측은 같은 819개 시험 배치를 두 모델로 예측한 것이므로 독립 표본 1,638개로 해석하지 않습니다. 아래는 기술 통계이며 유의성 검정이 아닙니다.

## 원인에 관한 근거와 다음 판단

3회차는 완료 측정 구간의 iPad 움직임뿐 아니라 검사 범위 전체에서 움직임 임계값 초과가 0건입니다. 정지 중 자력계 흔들림의 중앙값은 1/2/3회차 각각 0.642/0.615/0.600µT로 오히려 작아졌습니다. 반면 같은 인쇄점의 학습용 배경 보정 벡터 차이는 1↔2 중앙 2.067µT, 1↔3 2.828µT, 2↔3 2.579µT입니다. 즉 **정지 구간의 짧은 센서 흔들림보다 회차 사이 패턴 변화가 더 큰 현상**이 관찰됩니다. 자세·홀더·환경·배경 보정 오차 등의 어느 원인인지 이 데이터만으로 분리할 수는 없습니다. iPad IMU가 안정적이라는 사실로 Pencil 자세가 같았다고 보장하지 않습니다.

3회차 A12의 종료 배경까지 사용한 오프라인 진단 중앙 오차는 2.35mm(주 평가 2.19mm), B12는 2.51mm(주 평가 2.52mm)였습니다. 단순한 행별 선형 배경 보정만으로 이번 오차가 해소되지는 않았습니다. 이 진단은 실시간 성능으로 사용하지 않습니다.

현재는 **A123/B123을 동일한 배경·점·경로로 직접 비교**하고, 필요하면 12·2 등으로 전환해 점프·정지 흔들림·주황색 후보를 확인하는 것이 다음 단계입니다. A123이 독립 평가에서 가장 좋다고 선언한 것은 아닙니다. 이후 모델을 개선한다면 B의 위치별 패턴 중첩·판정 규칙을 분석하거나 시간적 연속성 모델을 별도 버전으로 비교할 수 있습니다. 튜닝에 사용한 세 회차와 구분되는 새 회차가 있어야 그 변경의 효과를 독립적으로 확인할 수 있습니다. 이번에는 그 튜닝을 하지 않았습니다.

- 39개 완료 세션, 819개 최종 정지점, 행별 앞뒤 배경 78개를 사용했습니다. 모든 행을 포함했습니다.

- 3회차 행별 시작/종료 배경 차이는 중앙 0.605µT, 최대 2.088µT, iPad 경사는 52.260–52.422°였습니다. 센서 파일 행 수와 manifest의 기록 수가 일치합니다.
- 1회차의 기존에 검토한 이동/준비 구간 경고와 2회차 13행의 타이밍 복구는 그대로 유지합니다. 원본을 고쳐 새 조건처럼 만들지 않았습니다.

- 이미 학습한 273개 좌표의 재배치 평가입니다. 점 사이의 새 위치·연속 필기·공중 높이·다른 φ/θ/α 성능을 입증하지 않습니다.

## 앱 사용과 기록

`273점 실시간` 화면에서 학습 회차 `1 / 2 / 3 / 1+2 / 2+3 / 1+3 / 1+2+3`와 A/B를 선택합니다. 기본값은 A123입니다. 배경은 준비 3초+측정 10초로 한 번 맞추고 같은 배치를 유지하는 동안 조합을 바꿀 수 있습니다. 조합 전환 시 궤적은 지워지고 로그가 새 파일로 이어지며 기존 배경과 그 원본 샘플·시각을 유지합니다. A/B 전환은 동일한 센서 입력으로 계산한 두 결과의 표시만 전환합니다.

평가 카드에는 선택한 모델이 **학습에 쓰지 않은 회차만** 기본으로 표시합니다. 학습 자료 재생 점수는 접힌 별도 영역이며 독립 평가가 아닙니다. 123에는 독립 평가 없음으로 표시합니다. CSV에는 조합·A/B 선택·두 예측을 기록하고, 옆에 실제 A/B 모델 사본과 SHA-256, 배경 샘플을 저장합니다. 자유 테스트에는 정답 좌표가 없어 자동 정확도로 취급하지 않습니다. 수집용 사전 평가 모델은 실시간 선택과 분리되어 2회차에는 A1/B1, 3회차에는 A12/B12로 기록됩니다.

## 구현 검증

Python 전체 48개 테스트를 통과했습니다. 앱에서 사용하는 Swift 구현과 Python 평가의 예측 924개를 14개 모델 전체에 걸쳐 비교했고 좌표·잔차·정상 표시·모호함 판정이 일치했습니다. 모델 해시가 틀리거나 학습 자료를 독립 시험으로 잘못 표시한 목록은 거부하는 검사도 통과했습니다. 기기 및 시뮬레이터 빌드가 성공했고, 실제 화면에서 A123의 독립 평가 없음 표시와 B12의 3회차 점수 전환을 확인했습니다. 아이패드 1.18 설치·실행 전후 수집 원본 392개 파일의 목록·크기·수정 시각이 동일합니다. 시뮬레이터에는 자력계가 없어 실제 펜 이동의 체감 정확도는 사용자의 기기 테스트로 확인합니다.
