# 오른쪽 중앙의 궤적 끊김 진단

2026-11-24 · 앱 1.18 · 사용자 요청에 따라 A/B × 7개 조합, 격자 전체, 최근 실시간 로그를 조사했습니다. 앱·모델·임계값·기존 원본은 변경하지 않았습니다.

**표시가 끊기는 직접 원인은 주로 위치 모호함 판정입니다. 2회차의 8행↔9행에서 회차 간 공간 패턴의 특이한 역전이 보이며, 여러 회차를 합친 B에서는 서로 다른 위치의 패턴이 경쟁하는 현상도 있습니다. 파일 누락이나 정지 측정 중 iPad 흔들림으로 설명되는 증거는 없습니다. 실제 Pencil 자세·표식 도착·홀더 상태는 측정하지 않았으므로 수집 조건 문제의 물리적 원인은 확정할 수 없습니다.**

`reports/spatial-rejection-20261124/rejection_maps.svg`는 14개 모델의 전 위치 진단 지도입니다. 각 칸은 정답 인쇄점 위치이며, 3번의 재생 중 보류된 횟수를 0–3으로 나타냅니다. 학습 자료를 포함하므로 정확도 지도라는 이름을 사용하지 않습니다.

## 왜 점과 궤적이 끊기는가

현재 A/B는 가장 가까운 자력계 패턴을 찾고, 정규화 XY 거리 0.2 이상 떨어진 다른 위치도 충분히 비슷하면 모호하다고 판정합니다. 기준은 `다른 위치 잔차 ≤ 최적 위치 잔차 + 0.75µT`입니다. 거리 0.2는 mm가 아니며 50×30mm 도면에서는 방향에 따라 대략 6–10mm입니다. A는 전체 보간 면의 후보를, B는 가장 가까운 저장 위치를 기준으로 이 검사를 합니다.

UI는 모호한 위치를 주황색 테두리 후보로 표시하지만 **청록색 궤적에는 넣지 않고 선을 끊습니다**. 후보가 있다가도 청록색 선이 사라지고 다음 정상 구간에서 이어지는 체감과 일치합니다. 약한 신호는 후보 자체를 숨기는 별도 조건입니다.

A2는 저장된 273개 대표값 그대로의 입력에서 27개 위치를 거부합니다. A123에서도 7행 19–21열 3개 위치를 거부합니다. A1/A3/A12/A23/A13은 이 특정 자기 입력 검사에서 0개였지만, 실제 측정 오차가 더해지면 보류가 생길 수 있습니다. 이 검사는 독립 정확도가 아니라 **지도와 판정 규칙 자체의 성질**입니다.

## 2회차의 8행↔9행 경계

각 열에서 8행→9행으로 움직일 때의 3축 벡터 변화 방향을 계산했습니다. 1·3회차 변화의 평균을 비교 기준으로 삼았을 때 **2회차는 21개 열 모두 반대 방향**이었습니다. 같은 조건에서 비교한 나머지 11개 행 경계에는 학습용 선형 배경 보정 기준으로 반대 방향 열이 없었습니다. 즉 한 점의 우연한 흔들림보다 **행 단위로 조건이 달라진 듯한 패턴**입니다. 이는 기준 회차에 상대적인 관찰이며, 물리적 원인을 확정한 것이 아닙니다.

이 역전은 시작 배경만 뺀 경우에도 21/21열, 종료 배경만 뺀 경우에도 21/21열에서 유지됩니다. 앞뒤 배경을 선형 보간하는 코드만으로 생긴 현상은 아닙니다. 다만 실제 배경이 선형으로 변했다고 보장하는 검사도 아니므로, 배경/주변 물체 영향 자체를 배제하지는 않습니다.

가장 오른쪽 21열의 배경 보정 후 벡터 크기 예시는 다음과 같습니다. 세 축 전체의 방향 검사와 함께 보는 보조 수치입니다.

| 회차 | 8행 벡터 크기 µT | 9행 벡터 크기 µT | 변화 |
|---|---:|---:|---|
| 1 | 18.575 | 17.540 | 감소 |
| 2 | 15.770 | 17.510 | 증가 |
| 3 | 15.263 | 14.350 | 감소 |

이 변화로 지도에서 멀리 떨어진 두 위치의 자력계 벡터가 가까워질 수 있습니다. 반복 자료를 합친 A의 대표값·보간 면, B의 여러 패턴 보존이 각각 다르게 이 영향을 받습니다. B13은 2회차 없이도 서로 다른 회차의 패턴이 경쟁할 수 있어서 별도의 회차 간 자세/배경 변화 영향도 검토해야 합니다.

## 원본 품질에서 확인한 것과 모르는 것

2회차 7·8·9행은 완료 점/열/순서/시간/라벨 검사를 통과하고, 각 행의 완료 점 21개가 있습니다. 이 세 행에는 무효화·중단된 시도도 없습니다. 검사 범위 내 iPad IMU 임계값 초과는 0건입니다. 정지점 잡음은 각 행 최대 약 0.678/0.673/0.669µT로 기존 3µT 기준보다 낮고, 오른쪽 점의 사용 표본은 69–70개였습니다. 행별 앞뒤 배경 차이는 약 0.854/0.705/2.550µT입니다. 기존 검사도 이번 진단도 이 파일을 손상된 수집으로 판정할 근거를 주지 않습니다.

하지만 위 검사는 **펜촉이 실제 목표점에 있었는지, Pencil의 φ·θ·α가 실제 같았는지**는 검증하지 못합니다. 저장된 자세는 수집 장치의 수동 설정 라벨이며 실측 Pencil IMU가 아닙니다. 가능한 원인은 Pencil/홀더 자세 변화, 실제 행 위치 차이, 홀더·주변 물체의 자기장 변화, 행별 배경 변화 등입니다. 고정 자세에서도 물리적으로 비슷한 신호가 생길 가능성 역시 이 기록만으로 분리할 수 없습니다. 사용자에게 수집 실수라고 단정하거나 행을 임의 삭제/재라벨링하지 않습니다.

## 권장하는 다음 확인

1. 바로 비교하려면 A3 또는 A13으로 같은 경로를 지나 보세요. 이번 진단 영역에서 보류가 적었기 때문이며, 전체 정확도가 항상 최고라는 뜻은 아닙니다. B13도 보류가 있어 A/B를 구분해야 합니다.
2. 수집을 추가한다면 먼저 6–10행의 **각 행 21점**을 같은 장치 설정에서 다시 측정하는 것이 전체 273점을 다시 재는 것보다 원인을 좁히는 데 도움이 됩니다. 8↔9행 전후의 공간 패턴과 배경을 비교하는 진단 수집으로 분리하고, 기존 2회차를 즉시 교체하지 않습니다.
3. 빠른 확인은 8행21열과 경쟁 후보 부근(10행20열·11행20열)을 번갈아 여러 번 놓아 신호가 실제로 겹치는지 보는 것입니다. 이는 정답 위치가 있는 새 진단이며 현재 앱의 자유 이동 로그만으로 대신할 수 없습니다.
4. 새 측정에서도 다른 위치의 신호가 겹친다면 단일 시점 자력계만으로 모호한 영역이 있는 것입니다. 시간적 이동 연속성을 쓰는 추정기를 별도 버전으로 시험할 수 있으나 시작 위치·재진입·실제 점프의 한계를 같이 평가해야 합니다. 새 진단 수집이나 모델 변경은 아직 적용하지 않았습니다.
