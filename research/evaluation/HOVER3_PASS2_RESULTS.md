# 공중 3 mm 2회차 · 고정 모델 평가와 1/2/12 비교

2026-11-25. φ=0°·θ=90°·α=0°, 높이 3 mm. **접촉은 1+3회차로 고정하고 공중은 1 / 2 / 1+2로 각각 구성한 통합 A/B/C 9개 조합**을 비교했습니다. 3 mm 전용 위치 A/B도 세 조합을 제공합니다. 기존 모델·원본은 보존했습니다.

배경 변화는 첫 회차보다 작았지만, 접촉/공중 분류는 여전히 불안정합니다. 추가 학습한 모델은 2회차를 더 잘 재생합니다. 그러나 공중 1+2 모델은 두 회차를 모두 학습했으므로 **별도의 독립 회차 성능 향상을 입증한 것은 아닙니다.** C의 같은 행 제외 비교에서도 추가 자료의 이득은 작았습니다.

## 자료 보존과 평가 순서

- 새 13세션·273점·91개 원본 파일을 iPad에서 가져왔습니다. 파일 크기는 기기 목록과 일치하고, CSV 행 수는 manifest 센서 수와 일치합니다. 불변 ZIP 13개와 개별 파일/ZIP SHA-256을 `datasets/`에 보존했습니다. 원본의 취소 시도도 유지합니다.
- 11행 13열의 한 시도는 움직임 감지로 취소됐고 재측정 완료됐습니다. 가속도 임계값을 넘은 두 표본은 취소된 준비/유휴 구간에만 있으며 완료 정지 구간과 겹치지 않습니다. 배경 변화는 0.148 µT입니다. [원본 해시로 제한한 검토](hover3_pass2_sources.json)를 남겨 잠정 포함했습니다. 미세한 평행이동·수평 회전이 없었다고 단정하지 않습니다.
- 모든 13행 manifest의 평가 모델 해시는 [수집 전 계획](hover3_pass2_plan.json)의 기존 A/B/C와 일치했습니다. 먼저 이 고정 모델로 2회차를 평가해 결과를 저장한 뒤 새 가중치를 만들었습니다. 새 학습 계획에는 그 평가 요약의 SHA-256을 넣었습니다.
- 기존 접촉 A13/B13과 공중 A1/B1, C1 가중치는 바이트 단위로 유지했습니다. 여기서 **C1/C2/C12는 접촉 1+3 고정 + 공중 1/2/1+2의 공동 신경망**입니다.
- C2/C12는 기존 C와 같은 3→64→64→3 구조, seed, Adam 2,000회, 손실 비율, 클래스별 50% 가중치, 배경 처리와 표시 기준을 사용했습니다. 자료 구성만 바꿨습니다. C2는 819배치/3,276대표값, C12는 1,092배치/4,368대표값이며 독립 측정 단위는 배치입니다.

## 배경 변화와 오판은 얼마나 줄었나

| 항목 | 공중 1회차 | 공중 2회차 |
|---|---:|---:|
| 행 시작–종료 배경 거리 중앙값 | 1.123 µT | 0.613 µT |
| 배경 거리 P95 / 최대 | 5.342 / 7.759 µT | 1.879 / 2.676 µT |
| 점 안 자기장 RMS 중앙값 | 0.589 µT | 0.594 µT |

배경 변화 중앙값은 약 **45.4%**, 최대값은 약 **65.5%** 작아졌습니다. 반면 정지 구간의 짧은 산포는 비슷합니다. 이는 수집된 배경 변화의 비교이며 **학습이 배경 자체를 줄인 결과가 아닙니다.** 시작·종료를 선형 보정한 뒤에도 두 공중 회차의 같은 XY 자기장 거리 중앙값은 **1.745 µT**입니다. 자세의 미세 차이, 배경 보정 잔여 오차, 배치 변화를 이 수치만으로 분리할 수 없습니다.

같은 공중 2회차에서 기존 공중 1 모델→공중 1+2 모델의 접촉 오판은 **A 27→15, B 28→0, C 54→46**입니다. 보류는 각각 **167→159, 215→160, 55→61**입니다. A/B는 정답 표시가 늘었고 C는 정답 164→166, 보류도 6개 늘었습니다. **회차 제외 평가→학습 자료 재생의 비교**이므로 이 감소량을 독립 성능 개선으로 발표하지 않습니다. 특히 B의 오판 0개에도 160/273개의 보류가 있습니다.

끝 배경까지 이용하는 오프라인 진단에서는 다음과 같습니다. 미래 배경을 사용하므로 실시간에 그대로 적용할 수 없습니다. 각 모델 가중치와 임계값은 고정하고 입력만 바꿨습니다.

| 공중 2회차 접촉 오판 | 시작 배경만 | 종료 배경까지 보정 |
|---|---:|---:|
| A1 / B1 / C1 | 27 / 28 / 54 | 4 / 9 / 40 |
| A12 / B12 / C12 | 15 / 0 / 46 | 3 / 0 / 18 |

C12의 오판 46→18과 보류 61→80은 잔여 배경 변화가 여전히 의미 있음을 보여줍니다. 단순히 더 많은 같은 자세 자료를 모으는 것만으로 배경 처리의 차이가 해결되지 않았습니다.

## 자료 추가 효과를 더 엄격하게 본 C 행 제외 비교

고정된 다섯 분할 `fold=(행-1)%5`에서 같은 행을 접촉·공중의 모든 학습 회차에서 통째로 제외했습니다. 공중 2회차의 제외된 행을 세 모델로 똑같이 평가합니다. C12도 해당 평가 행의 2회차 자료를 보지 않습니다. 정규화·표시 범위도 학습 행에서만 정합니다. **같은 캠페인의 공간 일반화 진단**이며 독립 회차 평가나 최종 전체 학습 모델의 점수가 아닙니다.

| 공중 학습 회차 · 행 제외 | 정답 / 오판 / 보류 · 273점 | XY 중앙 / P95 mm |

| 1 | 156 / 70 / 47 | 1.745 / 4.142 |
| 2 | 150 / 73 / 50 | 1.778 / 4.111 |

자료를 추가한 C12의 오판 감소는 70→67개, 정답 증가는 156→158개입니다. 중앙 위치 오차는 개선되지 않았고 P95만 조금 줄었습니다. 현재 증거로는 **C의 문제가 데이터 양 부족만이라고 보기 어렵습니다.** 높은 접촉/공중 유사도, 배경 변화, 신경망의 매끈한 근사·공동 손실 등의 영향이 남습니다. 구조별 인과 관계는 별도 대조 실험 없이는 확정하지 않습니다.

## 모델별 해석과 다음 시험

- **A**는 같은 위치의 회차들을 축별 중앙값으로 합쳐 한 자기장 지도를 만듭니다. 회차 차이가 있으면 가운데 지도가 되어, 2회차 재생은 개선돼도 1회차 재생에서는 오판 27→41로 나빠질 수 있습니다. ‘합치면 항상 개선’이 아닙니다.
- **B**는 회차별 패턴을 남기므로 추가한 2회차 재생에서 위치 오차와 오판이 크게 줄었습니다. 하지만 통합 모드의 높이 모호성은 여전히 커서 160점을 보류합니다. 공중 후보가 늘면서 접촉 재생의 정상 정답 표시도 365→311로 줄었습니다. 반대 회차를 평가하면 오판/보류가 다시 늘므로 암기 효과와 일반화를 구분해야 합니다.
- **C**는 독립 1→2 평가에서 올바른 공중 표시가 가장 많지만 오판도 많았습니다. 추가 자료에 따른 개선은 제한적이며, 이번에 배경 처리·손실·임계값을 동시에 바꾸지 않아 자료 구성 효과를 따로 볼 수 있습니다. 다음 개선 후보는 실제 운용에서 가능한 배경 갱신과 관측된 편향 변화에 대한 강건성입니다.

앱에서는 [실시간 안내](../docs/HOVER3_REPEAT_LIVE.md)대로 같은 배경으로 공중 학습 조합 1/2/12와 A/B/C를 바꿔 봅니다. 새 접촉 자료를 수집한 것은 아니므로 실제 0→3→0 mm 전환은 사용자의 개인 시험으로 확인해야 합니다. 중간 높이·새 자세·연속 필기의 정답 궤적 정확도는 검증하지 않았습니다.

## 재현과 검증

모든 명령은 `research/`에서 실행합니다. 작업 사본이 없다면 [원본 ZIP 목록](../../datasets/index.json)의 세션을 [sources](hover3_pass2_sources.json)에 지정한 경로로 복원합니다. 기존 [공중 1회차 분석](HOVER3_PASS1_RESULTS.md)과 [C1 학습](../docs/JOINT_NEURAL_MODEL.md) 산출물이 필요합니다. 생성 결과는 `reports/`에 두고 아래 핵심 요약·계획·코드·고정 모델을 Git에 남깁니다.

1. `build/joint-mlp-venv/bin/python scripts/analyze_hover3_repeat.py prepare`
2. `scripts/ReplayHeightModels.swift`를 기존 Core Swift 파일들과 함께 컴파일해 `build/tests/ReplayHeightModels`를 만듭니다. 아래 호출은 실제 앱 추정기 A/B/C를 재생합니다.
3. `build/tests/ReplayHeightModels MagAir/Resources hover3_1 joint_mlp_contact13_air1 reports/hover3-20261125-pass2/frozen-queries.json reports/hover3-20261125-pass2/frozen-before-training.json`
4. `build/joint-mlp-venv/bin/python scripts/analyze_hover3_repeat.py freeze-summary` 후 `build`를 실행합니다. 새 A/B 모델을 만들기 전에 고정 평가 요약 해시를 검사합니다.
5. `scripts/train_joint_mlp.py --source reports/hover3-20261125-pass2 --plan evaluation/joint_mlp_air12_plan.json --out reports/joint-mlp-20261125-air12`를 해당 venv Python으로 실행합니다. 이어 같은 명령의 `air12`를 `air2`로 바꿔 C2를 학습합니다. 기존 결과 폴더는 덮어쓰지 않습니다.
6. `scripts/analyze_hover3_repeat.py neural`을 venv Python으로 실행합니다. 아래 세 재생을 실행한 후 `summarize`, `bundle`을 실행합니다.
