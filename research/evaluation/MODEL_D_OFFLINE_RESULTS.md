# 위치별 A/B/C 분석과 실험 모델 D

2026-11-25. iPad 없이 보존된 측정으로 수행한 **사후 모델 개발·평가**입니다. φ=0°·θ=90°·α=0°, 50×30 mm sweet spot (스윗 스팟), 접촉 0 mm 1+3회차와 공중 3 mm 1+2회차를 사용했습니다. 접촉 2회차, 다른 자세, 중간 높이는 포함하지 않았습니다.

**D = 높이 전용 RBF SVM + B의 반대 판정 확인 + 별도 국소 선형 위치 회귀**를 구현했습니다. 다른 공중 회차 평가에서 C의 **320/114/112 → D 390/102/54**로 정답은 늘고 오판·보류는 줄었습니다. 그러나 새로운 행을 제외한 평가에서는 접촉의 공중 오판이 **98→173/546**으로 증가했습니다. 따라서 **공중 반복 시험용 후보로 보존하고, 기존 A/B/C를 대체하는 기본 모델로 채택하지 않습니다.** 모든 조건의 상당한 개선을 달성했다고 결론내리지 않습니다.

## 평가의 의미와 한계

- **공중 회차 교차 평가:** 접촉 1+3은 고정하고 공중 1로 학습→공중 2 평가, 공중 2로 학습→공중 1 평가. 각 273점, 합계 546점. 시험 회차는 각 모델의 가중치 학습과 내부 설정 선택에서 제외했습니다. 같은 물리적 273개 위치를 다시 잰 자료입니다.
- **양쪽 높이의 회차 제외:** 접촉 학습 회차 {1 또는 3} × 공중 학습 회차 {1 또는 2}, 총 4분할. 나머지 접촉·공중 회차를 모두 평가했습니다. C와 B도 동일 학습 집합으로 다시 만들었습니다. 높이별 집계 1,092건은 **546개 실제 측정을 두 학습 구성으로 평가한 것**이며 독립 측정 1,092개가 아닙니다.
- **행 제외:** `(행−1)%5`가 같은 행을 두 높이·모든 회차에서 함께 제외하고 5번 평가했습니다. 최종 1+2 학습 구성의 새 위치 일반화 진단입니다. C의 기존 동일 행 분할과 비교합니다.
- **최종 자료 재생:** 접촉 1+3·공중 1+2를 전부 학습하고 다시 평가합니다. 독립 평가가 아닙니다.
- 주 입력은 각 정지점의 앞뒤를 잘라낸 중앙값에서 해당 행의 **시작 배경만** 뺀 3축 값입니다. 점당 한 판정이며 보류를 분모에서 빼지 않습니다. 미래 종료 배경은 추론/평가 입력에 사용하지 않습니다.
- 0.12초 과거 구간 중앙값 3개/점도 별도로 재생했습니다. 실제 이동 궤적이나 접촉 전환 시험은 아니며 한 점의 세 구간은 서로 상관됩니다.
- 기존 자료는 이미 여러 차례 분석됐고, 이번 후보군·SVM 0.2 판정 여유·B 확인 규칙도 결과를 살펴보며 정했습니다. **학습/내부 선택의 분리는 지켰지만 최종 모델 선택까지 포함한 완전히 독립된 시험은 아닙니다.** 모든 수치는 탐색적·사후 결과입니다.
- 접촉과 공중은 서로 다른 수집 캠페인이므로 높이와 수집 시점/장치 변화가 얽혀 있습니다. 같은 자세의 두 높이 결과를 자유로운 필기·임의 자세·다른 높이의 성능으로 확대하지 않습니다.

## 기존 A/B/C에서 얻은 근거

아래는 공중 두 회차를 서로 제외해 평가한 결과의 합입니다. `위치 중앙/P95`는 **보류 후보도 포함**하고, `공중+2.5 mm`는 높이도 맞고 위치 오차도 2.5 mm 이하인 점입니다.

| 모델 | 공중 정답 | 접촉 오판 | 보류 | 표시 중 오판율 | 위치 중앙 / P95 mm | 공중+2.5 mm |
|---|---:|---:|---:|---:|---|---:|
| A | 160 | 70 | 316 | 30.4% | 1.859 / 5.052 | 126/546 |
| B | 66 | 79 | 401 | 54.5% | 2.093 / 5.228 | 44/546 |
| C | 320 | 114 | 112 | 26.3% | 1.661 / 4.590 | 233/546 |
| **D** | **390** | **102** | **54** | **20.7%** | **1.617 / 4.612** | **280/546** |

1. **A/B는 주로 높이 판정에서 막힙니다.** A 보류 316개 중 290개, B 보류 401개 중 395개가 높이 잔차 차이 0.75 µT 이내 조건에 걸렸습니다. 특히 B의 보류 중 98.5%입니다. ‘근처에 학습된 위치가 없어서’라는 설명만으로 부족합니다. 두 높이에서 서로 다른 XY가 비슷한 자기장을 만들 수 있습니다.
2. **단순한 A/B/C 구역 선택의 한계가 큽니다.** 정답을 알고 기존 A/B/C의 이미 나온 판정 중 최선을 고르는 불가능한 oracle도 공중 정답은 **326/546**입니다. C 단독 320에서 6개만 늘어납니다. A만 맞힌 경우 3개, B만 맞힌 경우 3개, C만 맞힌 경우 157개입니다. 이는 기존 판정을 그대로 선택하는 상한이며, 새 분류기를 학습하는 상한은 아닙니다.
3. **높이 정답과 위치 정밀도는 별개입니다.** 예를 들어 1–5행·15–21열에서 C는 공중 60/70점을 맞히지만, 그중 위치까지 2.5 mm 안인 점은 27개뿐입니다. ‘공중 색이 잘 뜬다’를 정확한 펜촉 좌표와 동일시하면 안 됩니다.
4. **C의 공유 신경망보다 높이 전용 학습을 시험할 이유가 있습니다.** C는 위치와 접촉을 한 네트워크로 최적화합니다. D에서는 높이만 결정하도록 분리하고 좌표는 별도 국소 회귀를 씁니다. 다만 전처리·모델 구조·표시 기준도 달라졌으므로 개선 원인을 ‘공유 손실 간섭 해소’ 하나로 입증한 것은 아닙니다.

## 위치에 따른 유불리

표는 행/열 번호 그대로이며 각 칸은 **정답 / 오판 / 보류**입니다. 행 1–5, 6–10은 구역당 70건, 행 11–13은 42건입니다. 이 구역은 분석용 정답 위치로 나눈 것이며 **D가 실제 정답 구역을 입력받아 모델을 고르는 방식이 아닙니다.**

| 행 | 열 | A | B | C | D |
|---|---|---|---|---|---|
| 1–5 | 1–7 | 19/34/17 | 4/37/29 | **24/38/8** | 18/42/10 |
| 1–5 | 8–14 | 14/23/33 | 9/22/39 | 30/25/15 | 37/27/6 |
| 1–5 | 15–21 | 42/0/28 | 40/0/30 | **60/0/10** | 59/5/6 |
| 6–10 | 1–7 | 3/7/60 | 3/6/61 | 19/26/25 | **49/13/8** |
| 6–10 | 8–14 | 4/2/64 | 0/13/57 | 40/10/20 | **56/1/13** |
| 6–10 | 15–21 | 31/0/39 | 2/1/67 | 53/2/15 | **63/1/6** |
| 11–13 | 1–7 | 0/0/42 | 1/0/41 | 27/0/15 | **42/0/0** |
| 11–13 | 8–14 | 14/0/28 | 0/0/42 | 34/6/2 | 34/5/3 |
| 11–13 | 15–21 | 33/4/5 | 7/0/35 | 33/7/2 | 32/8/2 |

**D의 큰 이득은 6–10행의 왼쪽·중앙과 11–13행 왼쪽입니다.** 6–10행·1–7열의 공중+2.5 mm 성공은 C 6→D 40/70으로 늘었습니다. 반대로 **1–5행·1–7열은 여전히 취약하고 D가 더 나쁩니다.** 오른쪽 위 구역의 접촉 오판도 C 0→D 5입니다. 따라서 ‘오른쪽/중앙에서 항상 D가 낫다’고 표현하지 않습니다.

위치 중앙 오차 역시 구역에 따라 다릅니다. 6–10행·8–14열은 C 1.565→D 1.305 mm, 1–5행·8–14열은 C 2.641→D 2.802 mm입니다. 전체 P95 4.590→4.612 mm는 사실상 개선되지 않았습니다.

## D의 동작

1. **높이 전용 SVM:** 배경 차감 Bx·By·Bz의 비선형 경계를 학습합니다. [RBF SVC](https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVC.html)를 사용하고 두 높이의 전체 학습 가중치는 같습니다. SVM 점수는 접촉 확률이 아닙니다. 점수 ≥0.2는 접촉, ≤−0.2는 공중, 사이는 보류합니다.
2. **별도 위치 회귀:** 시작 배경만 차감한 값과 선형 보정된 학습값을 함께 보관합니다. 입력과 가까운 24개 벡터 주변에서 가중 국소 선형 회귀로 연속 XY를 구합니다. 정답 격자에 좌표를 반올림하지 않습니다.
3. **B 확인:** 같은 학습 자료의 기존 B를 독립적으로 계산합니다. SVM과 B가 둘 다 판정했지만 서로 다르면 보류합니다. SVM이 보류하고 B가 판정하면 **B의 높이와 좌표**를 사용합니다. 그 외에는 SVM 높이·국소 회귀 좌표를 사용합니다.
4. 신호 3 µT 미만, 학습 지지 영역에서 6 µT 이상 이탈, XY가 허용 범위를 크게 벗어난 경우 등을 처리합니다. B 대체 판정도 B 자체의 기존 신호·거리·위치 모호성 기준을 통과해야 합니다.

목표 좌표·행/열·회차·높이·시간·φ/θ/α·Pencil IMU는 추론에 들어가지 않습니다. 종료 배경은 학습 관측을 만드는 데만 쓰이며 새 입력에는 사용하지 않습니다. 외부 장치 없이 같은 iPad 자력계 입력으로 실행할 수 있습니다.

SVM의 전처리/커널 폭/규제는 **바깥 시험 자료를 제외한 학습 자료 내부의 전체 행 3분할**에서 정했습니다. 내부 목적은 두 높이 평균 `오판율 + 0.35×보류율`입니다. 판정 여유 0.2와 최종 B 결합 규칙은 탐색 과정에서 정한 것이므로 사전 고정 시험으로 포장하지 않습니다. 같은 행/배치의 대표값을 임의 표본 분할로 학습·검증에 섞지 않았습니다. [그룹을 고려한 검증 원칙](https://scikit-learn.org/stable/modules/cross_validation.html)을 따르되, 두 캠페인만 있다는 한계는 남습니다.

최종 공중 1+2 후보는 mixed 입력, 등방 거리, 커널 폭 16 µT, SVM C=100을 선택했습니다. 회차 교차 시험의 두 후보는 선형 배경 보정 입력, 축 표준화, 폭 16, C=100을 선택했습니다. 이것은 각 학습 집합에서 같은 선택 절차를 다시 수행한 결과입니다.

## 주 결과와 짧은 구간 재생

| 학습 공중 → 평가 공중 | C 정답/오판/보류 | D 정답/오판/보류 |
|---|---|---|
| 1 → 2 | 164 / 54 / 55 | **200 / 45 / 28** |
| 2 → 1 | 156 / 60 / 57 | **190 / 57 / 26** |
| 합계 | 320 / 114 / 112 | **390 / 102 / 54** |

C 대비 정답률 **58.6→71.4% (+12.8%p)**, 공중 정답 수 **+21.9%**, 접촉 오판 수 **−10.5%**, 보류 수 **−51.8%**입니다. 높이와 2.5 mm 위치 조건을 동시에 만족한 비율은 **42.7→51.3%**입니다. 정답·보류 쪽 변화가 오판 감소보다 큽니다.

13개 물리 행을 군집으로 묶고 두 모델·두 회차를 함께 재표집한 탐색적 95% 구간에서 D−C 변화는 정답률 **+5.1~+20.7%p**, 접촉 오판율 **−7.3~+3.1%p**, 보류율 **−16.8~−4.8%p**입니다. **오판 감소 구간에는 0이 포함됩니다.** 모델 선택 편향과 두 회차밖에 없는 불확실성은 이 구간에 포함되지 않아 확증 통계로 사용하지 않습니다.

실시간과 같은 0.12초 과거 구간 필터에서도 방향은 유지됐습니다. 총 1,638개 상관된 프레임에서 C **940/370/328 → D 1,148/309/181**, 공중+2.5 mm 성공은 **673→825**입니다. 정지 중앙값에서만 생기는 개선은 아니지만 연속 이동 성능을 입증한 것도 아닙니다.

## 접촉까지 새 회차로 바꾸면

각 높이에서 한 회차씩 학습하고 남은 회차를 시험한 4개 조합의 합입니다. 각 높이 1,092평가건이며 각 실제 측정은 두 번 평가됩니다.

| 실제 상태 | C 정답/반대 상태 오판/보류 | D 정답/반대 상태 오판/보류 | C → D 위치 중앙/P95 mm |
|---|---|---|---|
| 공중 | 663/228/201 | **712/228/152** | 1.658/4.981 → 1.592/4.437 |
| 접촉 | 505/386/201 | **571/382/139** | 2.245/6.217 → 1.868/4.997 |

정답 증가·보류 감소와 위치 오차 개선은 있지만, 공중 오판은 그대로이고 접촉 오판 감소도 4건뿐입니다. 회차 전체가 바뀌면 C와 D 모두 접촉 판정이 불안정합니다. **단순히 공중 데이터가 적다는 문제만은 아닙니다.**

|---|---|---|
| 공중 | 329/119/98 | 342/124/80 |
| 접촉 | **266/98/182** | **260/173/113** |

접촉을 공중으로 잘못 읽는 비율이 **17.9→31.7%**로 커집니다. D가 덜 보류하는 정책이 학습하지 않은 공간에서는 오판으로 바뀌는 중요한 반례입니다. 펜촉이 표시한 점 사이를 지나갈 때도 잘 될 것이라고 이 결과로 보장할 수 없습니다. **이 결과 때문에 기본 모델 자동 교체를 보류했습니다.**

## 전체 학습 후 재생과 자료 추가

접촉 1+3·공중 1+2를 전부 학습한 모델의 자기 자료 재생입니다.

| 실제 상태 · 각 546점 | C 정답/오판/보류 | D 정답/오판/보류 | C → D 위치 중앙/P95 mm |
|---|---|---|---|
| 공중 | 339/101/106 | **429/60/57** | 1.444/3.649 → **0.910/2.849** |
| 접촉 | 346/66/134 | **380/96/70** | 1.279/3.873 → **0.858/2.723** |

두 공중 회차를 학습한 후보는 공중 재생에서 더 좋지만 접촉 오판은 늘었습니다. 새 데이터 추가가 항상 모든 지표를 개선하는 것은 아닙니다. 이 표는 앞의 1→2/2→1 시험과 평가 역할이 다르므로 숫자 차이를 데이터 추가의 독립 성능 이득으로 계산하지 않습니다.

| 보수적 SVM | 277 / 65 / 204 | 같은 한계 |
| SVM 단독, 판정 여유 0.2 | 414 / 99 / 33 | 공중은 유리하나 접촉 오판 증가; 그대로 채택하지 않음 |
| 매끈한 순방향 자기장 지도 | 299 / 143 / 104 | 기존 C보다 낮은 정답, 더 많은 오판 |
| SVM·C·원형 거리의 학습된 결합 | 287 / 132 / 127 | 행 분리 예측으로 결합해도 일반화 개선 없음 |
| 높이 전용 부스팅 트리 | 128 / 46 / 372 | 과도한 보류 |
| 배경 변화 방향을 반영한 SVM | 400 / 101 / 45 | 단독 SVM보다 공중 성능이 낮음 |
| **선택 후보 D: SVM+B 확인** | **390 / 102 / 54** | 공중 성능 일부를 양보하고 접촉 위험을 점검; 공간 일반화 문제는 남음 |

단독 SVM의 양쪽 높이 회차 제외 시험은 접촉 오판 411건, B 확인을 더한 D는 382건이었습니다. 공중 정답은 743→712로 줄어드는 비용을 감수했습니다. 따라서 D는 공중 숫자만 가장 높은 후보를 고른 것이 아닙니다.

## 저장 위치·실행·검증

- 선택한 공중 1/2/1+2 D 가중치와 해시: [실험 모델 목록](experimental/model_d_catalog.json). 이 디렉터리는 앱 번들이 아니며 iPad에 설치하지 않았습니다. 기존 A/B/C 및 원본 ZIP은 변경하지 않았습니다.
- [D 설계·선택 기록](model_d_hybrid_plan.json), [기본 SVM 탐색 계획](model_d_balanced_plan.json), 나머지 `model_d_*_plan.json`에 후보·선택 시점을 남겼습니다.
- 수천 건의 개별 예측·중간 모델·선택 점수·군집 재표집 결과는 `reports/model-d-20261125-*`에 생성됩니다. 생성 보고서는 Git에서 제외하고 코드·계획·이 기록·선택 가중치를 보존합니다.
- 그림은 `reports/model-d-20261125-hybrid/cross_pass_height_maps.png`, `air_outcome_comparison.png`입니다. 행/열 방향은 수집 앱 번호 기준입니다.
- Mac에서 최종 JSON 모델을 점당 실행한 100개 입력의 중앙 시간은 약 1.38 ms였습니다. iPad 지연 측정이 아니며 앱 실시간 성능으로 주장하지 않습니다. 학습에는 scikit-learn을 쓰지만 내보낸 D 추론은 NumPy만 필요합니다.

모든 명령은 `research/`에서 실행합니다. 먼저 [이전 데이터 추출·A/B/C 재생 절차](HOVER3_PASS2_RESULTS.md#재현과-검증)로 `reports/hover3-20261125-pass2`와 C 행 분리 결과를 준비합니다.

```sh
build/joint-mlp-venv/bin/python -m pip install -r requirements-model-d.txt
build/joint-mlp-venv/bin/python scripts/experiment_model_d.py --plan evaluation/model_d_balanced_plan.json --out reports/model-d-20261125-balanced --stage all
build/joint-mlp-venv/bin/python scripts/compare_model_d.py paired --out reports/model-d-20261125-baselines
build/joint-mlp-venv/bin/python scripts/finalize_model_d.py --out reports/model-d-20261125-hybrid
build/joint-mlp-venv/bin/python scripts/plot_model_d.py
build/joint-mlp-venv/bin/python -m unittest discover -s tests -p 'test_model_d.py' -v
build/joint-mlp-venv/bin/python scripts/predict_model_d.py --field 0 0 0
```

마지막 명령은 약한 신호 보류를 확인하는 예시이며 실제 자기장 입력은 해당 시점의 배경을 먼저 빼야 합니다. `--model evaluation/experimental/model_D_contact13_air1.json` 또는 `air2.json`으로 다른 학습 조합도 실행할 수 있습니다.

이미 고정한 JSON 모델은 저장소에 포함됩니다. 재현 실행은 별도 보고서에 수치·판정을 비교하며 고정 파일을 덮어쓰지 않습니다. 새 후보를 처음 고정할 때만 `finalize_model_d.py --export`를 사용합니다. 기존 파일과 바이트가 다르면 중단하므로 라이브러리/부동소수점 차이를 포함한 변경 모델은 새 버전으로 보존해야 합니다.

다른 후보는 각 계획과 고유 출력 폴더를 지정해 `experiment_model_d.py --stage crosspass`로 재현합니다. 계획 이름/폴더 접미사 대응은 `model_d_plan.json`→`v1`, `model_d_svm_plan.json`→`svm`, `model_d_forward_plan.json`→`forward`, `model_d_boost_plan.json`→`boost`, `model_d_noise_plan.json`→`noise`입니다. 결합 후보는 `experiment_model_d_stack.py --out reports/model-d-20261125-stack --stage crosspass`를 사용합니다.

검사 항목: SVM/트리 JSON 추론과 원 라이브러리 일치, B 확인의 기존 Swift 재생 결과 일치, 외부 시험 trial·세션·행이 학습에서 제외됨, 정답 좌표/라벨을 바꾸어도 추론 불변, 미래 입력을 덧붙여도 현재 추론 불변, 약한/범위 밖/비정상 입력 처리. 5개 신규 검사와 4개 기존 공동 모델 검사를 통과했습니다. 동일 설정의 SVM 회차 평가를 재학습해 판정 개수도 재현했습니다.

## 다음 판단

D는 공중의 빈번한 사라짐을 줄일 후보지만 접촉까지 해결한 최종 모델은 아닙니다. 추가 자료를 모을 때에는 전체 격자를 같은 높이로 다시 반복하는 것보다 **취약한 1–5행 왼쪽과 개선된 중앙 구역의 일부 동일 XY에서 0→3→0 mm를 교대로 측정**하는 시험이 높이와 시간/배경을 분리하는 데 더 유용합니다. 전체 새 수집을 지금 요구하는 것은 아니며, 다음 전향 시험에서는 D와 임계값을 먼저 고정하고 중간 위치·접촉 전환까지 기록해야 합니다.
