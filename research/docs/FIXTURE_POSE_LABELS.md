# 장치 자세 라벨 · φ, θ, α

**2026-11-24 후속 결정:** 같은 자세로 3회차까지 수집하고 각 새 회차를 먼저 평가한 뒤 병합합니다. [현재 평가 계획](../evaluation/README.md)과 [2초 자동 수집 안내](FAST_COLLECTION.md)를 따릅니다. 아래의 당시 미정 사항과 수집 시간은 역사 기록입니다.

2026-11-23 사용자가 확인한 정의입니다. 기존 φ·θ를 유지하고 α를 추가합니다. 각 값은 **장치에서 맞춘 설정값**이며 Pencil IMU 실측이나 실시간 추론 입력이 아닙니다.

| 값 | 정의 |
|---|---|
| φ | 홀더 전체를 책상 수직축 주위로 회전. 탑뷰 시계방향 +, 기존 방향 0°. 360°는 0°와 같음 |
| θ | **α=0일 때** 펜 축과 지면 사이의 각도. 수평 0°, 수직 90° |
| α | 초기 펜의 책상 투영선을 경첩 축으로, 펜이 속한 초기 수직면을 옆으로 기울이는 각도. −90°~+90°, 초기 상태 0°. **φ와 함께 돌아가는 장치 기준 오른쪽이 +** |
| 높이 | 펜촉과 종이 표면 사이의 연직 거리 mm. 접촉 0, 공중 양수 |

θ를 먼저 맞춘 기준 자세를 정하고, 그 자세의 경첩 기준선에 대해 α를 적용합니다. φ는 이 장치 전체의 책상 수직축 방향입니다. α가 바뀌어도 θ 라벨을 최종 지면 각도로 다시 계산하지 않습니다. 예를 들어 θ=70°, α=20°이면 두 값 그대로 저장합니다. φ는 펜 자체의 긴 축 회전으로 바꾸지 않습니다. 펜이 그립 안에서 따로 도는 회전은 고정합니다.

θ=90°에서는 펜 축의 책상 투영 길이가 0이므로 그 투영만으로 경첩 축을 정할 수 없습니다. **장치에 정한 기준선**을 사용합니다. θ<90° 또는 α≠0°인 수집에서는 배치 확인의 `φ=0의 경첩 기준선 / θ를 낮출 때 기울어지는 쪽`에 실제 기준을 입력해야 합니다. 그 방향은 아직 대신 결정하지 않았습니다. 양수의 오른쪽은 사용자가 항상 바라보는 고정 화면의 오른쪽과 다를 수 있습니다.

## 파일과 호환성

새 수집은 `schemaVersion=2`, 앱 1.15.0입니다. `manifest.printedGrid.pose`와 정지점의 `fixturePose`에 `alphaDegrees`, `alphaDefinition`, `alphaLabelSource`를 기록합니다. CSV에는 `fixture_alpha_deg`, `fixture_alpha_source`가 추가됩니다. 다른 자세·높이를 시작할 때는 새 배치를 사용해 기존 자료와 구분합니다.

CSV 자세 라벨은 실제 정지 측정(`hold`)에만 기록합니다. 이동·준비·배경에는 비워 둡니다. 각도는 새로운 수집에서 `operator_set_fixture_unmeasured` 출처로 저장됩니다. `schemaVersion=1`도 계속 읽지만, α가 없는 자료를 자동으로 0으로 처리하지 않습니다.

첫 273점 수집은 사용자가 **φ=0°, θ=90°, α=0°, 높이=0 mm**였다고 확인했습니다. 별도 [보완 라벨 목록](../MagAir/Resources/fixture_pose_annotations.json)에 13개 세션과 원본 manifest의 SHA-256, 확인 날짜·출처를 기록했습니다.

- 원본 CSV/manifest를 고치거나 α 열을 끼워 넣지 않습니다.
- 분석은 목록의 세션·배치·기존 자세·원본 해시가 일치할 때만 α=0 보완 라벨을 적용합니다.
- 앱은 동일 배치의 저장된 조건과 완료 이력을 읽을 때 목록의 세션/조건에 보완 라벨을 적용합니다. 원본 파일을 다시 저장하지 않습니다.
- 다른 미기록 자료는 α 미상으로 남고 모델 생성에서 거부합니다.
- 첫 회차 실시간 모델에는 α=0과 사후 확인 출처를 추가했습니다. 자기장 지도와 추정 계산은 바꾸지 않았습니다.

## 다음 수집

사용자는 같은 자세의 2·3회차에 앞서 다른 자세를 수집하는 방안을 고려 중입니다. **각도 조합·반복 횟수·여러 자세를 학습할 모델은 아직 결정하지 않았습니다.** 기존 반복 슬롯은 보존하며 다음 필수 작업으로 요구하지 않습니다. 현재 고정 자세 모델이 다른 φ·θ·α에 일반화하도록 개선된 것은 아닙니다.

같은 위치에서도 자세에 따라 자기장 벡터가 달라질 수 있습니다. 다른 자세의 자료를 모은 뒤에는 위치와 자세의 혼동, 반복성, 별도 세션 검증을 포함해 모델을 결정해야 합니다. 이 문서는 그 실험이나 모델 선택을 미리 확정하지 않습니다.

## 1.15 검증

연구 Python 검사 39개와 Swift 핵심 검사를 통과했습니다. 음수/양수 α, 범위, 수직 상태의 경첩 기준선, 누락값 거부, 원본 해시가 다른 자료의 보완 라벨 거부, 다른 자세 혼합 거부를 포함합니다. 실제 첫 회차 13행의 완료 이력을 복원했고 원본은 수정하지 않았습니다. 819개 재생 구간에서 Swift/Python 추정 결과가 계속 일치합니다.

시뮬레이터에서 α=-15° 입력 및 기준선 입력란을 확인했고 저장하지 않고 닫았습니다. 연구 앱의 iPad 빌드·설치·실행을 확인했습니다. 업데이트 전후 기기의 196개 측정 파일은 크기와 수정 시각이 같았습니다. 보존한 데모도 별도의 Swift/Python 31개 검사를 통과했습니다. 이 검사는 새로운 자세에서의 실제 추정 정확도 검증이 아닙니다.
