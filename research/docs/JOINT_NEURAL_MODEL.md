# C · 위치와 접촉 공동 학습 · 1.22.0(27)

2026-11-25 사용자 요청으로 **0 mm 1+3회차와 3 mm 1회차를 하나의 모델에 함께 학습**했습니다. 기존 높이별 A/B 모델과 잔차 비교 방식은 유지합니다. C는 높이별 모델의 승자를 고르는 방식이 아니라, 하나의 공유 신경망에서 XY와 접촉 점수를 동시에 출력합니다.

## 실시간 사용

**A/B/C 실시간 테스트 → 통합 · 0 / 3 mm → C · 공동 학습**을 선택합니다. 이번 설치는 C로 열립니다. φ=0°·θ=90°·α=0°와 iPad·도면·스탠드 배치를 유지하고, 펜과 홀더를 멀리 두어 **준비 3초 + 배경 10초**를 측정합니다.

같은 스윗 스팟 위치에서 0 → 3 → 0 mm로 바꾸거나 각 높이에서 선을 따라 움직입니다. A/B/C 전환은 지도와 궤적의 표시만 바꿉니다. 세 방식은 같은 0.12초 인과적 필터 입력·실시간 배경으로 함께 계산·저장되므로 전환마다 배경을 다시 측정할 필요가 없습니다. 지도 아래 표에서 같은 순간의 세 모델 좌표와 접촉 판정을 볼 수 있습니다.

청록색은 접촉, 보라색은 3 mm 공중 추정입니다. 주황색은 판정 보류이며 후보 좌표도 참고용입니다. 색이 바뀌거나 판정을 보류하면 궤적을 끊습니다. 0/3 mm 사이의 중간 높이와 다른 자세는 아직 학습하지 않았습니다. C는 통합 모드에서만 선택되며 단일 높이 모드로 옮기면 기존 A로 전환됩니다.

## 실제 학습한 것

- 입력: 배경을 뺀 Bx·By·Bz, 세 값뿐입니다. 장치 자세·목표 좌표·높이·행 번호·이동 시간·Pencil IMU는 추정 입력이 아닙니다.
- 정답: 50×30 mm 도면상의 x·y, 접촉 1 / 공중 0.
- 구조: **3 → 64 → 64 → 3**, 두 은닉층은 tanh. 마지막 세 출력은 중심을 뺀 x·y(25 mm 단위)와 접촉 logit입니다. XY는 선형 출력이고 접촉 logit에는 sigmoid를 적용합니다.
- 학습 손실: 위치의 제곱 오차와 접촉의 이진 교차엔트로피를 함께 최소화합니다. 두 손실 모두 공유 은닉층 가중치를 갱신합니다. 접촉 손실 계수는 0.2, 가중치 L2는 0.00001입니다.
- 학습 데이터: 접촉 546배치 + 공중 273배치 = **819배치**. 각 배치의 정지 대표값과 3개 짧은 구간 대표값을 사용해 3,276벡터를 만들었습니다. 같은 배치의 네 벡터는 상관된 관측이며 독립 실험 네 번으로 세지 않습니다.
- 클래스 가중치: 접촉과 공중 각각 전체 손실 가중치의 50%를 차지합니다. 접촉 회차가 두 배라는 이유만으로 접촉을 더 선호하는 학습을 줄이려는 설정입니다.
- 학습 시 각 행의 시작·종료 배경을 선형 보정합니다. 실시간과 주 평가 입력에는 시작 배경만 사용합니다. 입력의 평균·표준편차도 학습 부분에서만 구합니다.
- 고정 설정: seed 20261125, full-batch Adam 2,000회, 학습률 0.003→0.0003 cosine. 구현은 NumPy이며 iPad에는 학습된 가중치와 Swift 계산 코드만 들어갑니다.

[고정 계획](../evaluation/joint_mlp_plan.json)을 C의 학습·성능 확인 전에 작성했습니다. 이번에는 설정 탐색이나 평가 결과에 따른 임계값 조정을 하지 않았습니다. 이미 기존 A/B와 높이 비교 결과를 본 뒤 제안한 모델이므로 사전 등록된 연구 실험이라고 주장하지 않습니다.

교차엔트로피 계산은 sigmoid를 직접 로그로 취하는 대신 안정적인 logits 형태를 사용합니다. 수식 설명은 [공식 BCEWithLogitsLoss 문서](https://docs.pytorch.org/docs/stable/generated/torch.nn.BCEWithLogitsLoss.html), 난수 초기화는 [NumPy Generator 문서](https://numpy.org/doc/2.3/reference/random/generator.html)를 참고했습니다. 이 학습기에 PyTorch 의존성은 없습니다.

## C의 표시 기준

접촉 점수는 **보정되지 않은 신경망 출력**이며, 표시 정확도 확률이 아닙니다.

- 점수 ≥ 0.65: 접촉 후보.
- 점수 ≤ 0.35: 공중 후보.
- 그 사이: 접촉·공중 판정 보류.
- 신호가 약하거나 학습 자기장 벡터에서 너무 멀면 표시를 보류합니다. 가장 가까운 학습 벡터까지의 거리는 **보류 판단에만 사용**하며 XY나 높이를 선택하지 않습니다. 이 기준은 `max(3 µT, 학습 정지 구간 최대 RMS × 5)`입니다.
- 출력 좌표가 정규화 범위 [-0.05, 1.05] 밖이면 보류합니다. 경계에 맞춰 좌표를 잘라서 정답처럼 보이게 하지 않습니다. 이 허용 범위 때문에 모서리 부근에서는 조금 바깥의 좌표도 표시될 수 있습니다.

C는 A/B의 ‘서로 떨어진 두 위치가 비슷한 신호를 갖는지’ 검사를 그대로 사용하지 않습니다. 겹치는 입력에서 좌표를 평균에 가까운 곳으로 예측하거나 잘못된 색에 높은 점수를 줄 수 있습니다. 세 방식의 보류 기준이 달라 표시율과 오판 수를 함께 비교해야 합니다.

## A/B/C 동일 자료 재생 · 독립 정확도 아님

세 방식 모두 같은 819개 배치와 시작 배경만 뺀 정지 대표값을 사용했습니다. 최종 모델이 이미 학습한 자료입니다. C만의 평가 분할 결과와 섞지 않습니다. XY 중앙/95% 오차는 보류된 점까지 포함한 전체 후보의 2차원 거리입니다.

| 모델 | 실제 높이 | 배치 수 | 올바른 색 | 잘못된 색 | 판정 보류 | XY 중앙 / 95% 오차 mm |
|---|---|---:|---:|---:|---:|---|
| A | 0 mm | 546 | 247 | 13 | 286 | 1.199 / 3.333 |
| A | 3 mm | 273 | 105 | 27 | 141 | 0.667 / 3.718 |
| B | 0 mm | 546 | 365 | 0 | 181 | 0.163 / 1.966 |
| B | 3 mm | 273 | 83 | 10 | 180 | 0.378 / 3.712 |
| C | 0 mm | 546 | 365 | 63 | 118 | 1.317 / 3.636 |
| C | 3 mm | 273 | 174 | 58 | 41 | 1.523 / 4.175 |

C는 특히 공중에서 판정 보류를 줄이고 올바른 색을 내는 수를 늘렸지만, 오판도 늘었습니다. 이 자료에서는 C의 위치 오차가 A/B보다 작지 않습니다. B는 학습 패턴을 직접 보관하므로 자기 자료 재생에서 유리할 수 있습니다. **C가 더 좋다는 결론은 내리지 않으며**, 같은 위치에서 높이를 바꿀 때의 색·좌표 흔들림을 실기기에서 비교합니다.

## C의 행 단위 분리 평가

`fold=(행-1)%5`로 다섯 번 나눕니다. 한 평가 행에 해당하는 **두 높이·모든 접촉 회차·모든 짧은 구간**을 함께 학습에서 제외합니다. 각 분할마다 모델·정규화·표시 범위 기준을 새로 구합니다. 예측에는 행/좌표/정답 높이가 들어가지 않습니다.

| 실제 높이 | 배치 수 | 올바른 색 | 잘못된 색 | 판정 보류 | XY 중앙 / 95% 오차 mm |
|---|---:|---:|---:|---:|---|
| 0 mm | 546 | 300 | 84 | 162 | 1.492 / 4.279 |
| 3 mm | 273 | 154 | 64 | 55 | 1.827 / 4.788 |

보류를 무시하고 점수 0.5로 강제 분류한 높이 정답 비율은 접촉 76.01%, 공중 68.13%, 두 클래스 평균 72.07%입니다. 앱의 실제 표시 기준을 적용한 ‘올바른 색’ 비율은 각각 54.95%, 56.41%입니다. 위의 강제 분류 비율을 앱 정확도로 소개하지 않습니다.

이는 같은 수집 배치 안에서 학습하지 않은 행으로 일반화하는지 본 결과입니다. **독립적인 3 mm 반복 수집 검증은 여전히 없습니다.** 접촉/공중은 서로 다른 캠페인에서 수집돼 높이 변화와 환경 변화가 얽혀 있습니다. 이전 다른 분류기의 행 제외 실험과 분할·알고리즘·표시 기준이 달라 수치를 바로 비교하지 않습니다. 최종 앱의 C는 분리 평가 후 819배치를 모두 학습한 모델입니다.

