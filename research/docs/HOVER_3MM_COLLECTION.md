# 3 mm 비접촉 수집 · 2026-11-24

**2026-11-25 후속: 공중 2회차는 [1.23 수집 안내](HOVER3_PASS2_COLLECTION.md)를 따릅니다.** 같은 배치를 2회차까지 확장했으며 1행 오른쪽에서 시작합니다. 아래는 첫 회차의 역사적 절차입니다.

**2026-11-25: 13행·273점 완료 및 원본 보존·분석을 마쳤습니다. [분석 결과와 다음 수집 제안](../evaluation/HOVER3_PASS1_RESULTS.md)을 참고하세요.** 아래는 당시 적용한 수집 절차입니다.

앱 **1.19.0 (24)**에서 기존 접촉 배치와 분리한 새 배치를 준비합니다. 사용자는 장치의 높이만 3 mm 올렸다고 확인했습니다. 각도·펜 고정 방향·종이·iPad·스탠드 위치는 기존 조건을 유지합니다.

| 항목 | 이번 설정 |
|---|---|
| φ / θ / α | 0° / 90° / 0° |
| 펜촉 높이 / 상태 | 종이 표면에서 연직 3 mm / 비접촉 (`air`) |
| 위치 | 50 × 30 mm 스윗 스팟의 21열 × 13행, 간격 2.5 mm |
| 이번 분량 | 1회차 273점, 13행. 이후 반복 수집 횟수는 첫 분석 뒤 결정 |
| 순서 | 1 → 13행. 홀수 행 왼쪽→오른쪽, 짝수 행 오른쪽→왼쪽 |
| 각 점 | 이동·준비 3초 + 정지 측정 2초, 행 안 자동 진행·안내음 |
| 각 행 | 시작 배경 → 21점 → 종료 배경. 배경마다 준비 3초 + 측정 10초 |

## 사용

1. **273점 수집 → 배치 확인하고 준비 완료**에서 높이 3 mm·공중과 각도를 확인합니다. 물리적 고정 상태를 확인한 다음 준비 완료를 누릅니다. 이번 전용 배치의 자세 라벨은 고정되어 있습니다.
2. 펜과 이동 홀더를 평소 배경 측정 위치로 멀리 옮겨 **배경 시작**을 누릅니다. 배경에는 3 mm·비접촉 정답을 부여하지 않습니다.
3. 첫 표식의 **수직 위 3 mm**에 펜촉을 놓고 연속 시작합니다. XY 기준은 홀더 중심이 아닌 펜촉의 수직 투영점입니다. 종이에 닿도록 내리지 않습니다.
4. 21점 이후 펜과 홀더를 시작 배경 때의 먼 위치로 옮겨 종료 배경을 측정합니다. 행 저장 완료를 확인한 뒤 다음 행으로 진행합니다.
5. **13/13행**을 마치면 완료라고 알립니다. 자동으로 2회차를 요구하지 않습니다. 자동 진행과 저장 대기를 합쳐 약 30분이며 수동 이동·휴식 시간은 별도입니다.

3 mm 높이와 접촉 여부는 장치에서 사람이 설정한 라벨입니다. Pencil IMU나 접촉 센서로 측정하지 않습니다. iPad 중력·가속도·자이로·자력계와 화면 경사 기록은 계속 수집합니다.

설치 후 실제 iPad에서 읽어 확인한 새 배치 번호는 `SweetSpot-FB8B1625-27C7-4190-B577-128C7EE38D04`입니다. 0/13행·첫 시작 배경부터 준비하며 측정은 자동으로 시작하지 않았습니다.

## 배치 구분과 보존

- 새로운 무작위 `campaignID`를 부여하고 `referenceCampaignID`에 접촉 배치 `SweetSpot-1EBFFD3B-454D-4F78-90F2-6F50069B43C8`를 남깁니다. 기존 접촉 1·2·3회차의 원본과 14개 모델은 변경하지 않습니다.
- `plannedPasses=1`, `collectionIntent=contact_0mm_vs_air_3mm_feasibility; operator-set height, no sensed contact; first pass only`를 각 행의 `printedGrid` 메타데이터에 기록합니다. 정지 구간만 `fixture_tip_state=air`, `instructed_tip_height_mm=3`과 φ·θ·α를 기록합니다.
- 앱 설정 전환 전에 이전·새 배치 조건 JSON을 `Documents/MagAirCampaigns/`에 내용의 SHA-256을 붙인 이름으로 보존합니다. 세션 원본을 고치거나 삭제하지 않습니다. 완료 측정은 기존 절차대로 `datasets/`의 원본 ZIP과 해시 목록에 보존합니다.
- 이번 전환은 명시적인 실행 인자 `--prepare-hover3`로 한 번만 적용합니다. 같은 인자로 재실행해도 배치 번호나 완료 이력을 초기화하지 않습니다. 일반 실행도 해당 배치의 수집 탭으로 열립니다. 첫 시작 배경은 사용자가 직접 시작합니다.
- 첫 행부터 새 배치의 완료 기록만 집계합니다. 과거 접촉 행 번호가 같더라도 새 배치의 완료로 처리하지 않습니다. 기존 3회차 배치는 계속 39행으로 해석합니다.

## 수집 후 판단할 것

이번 자료는 같은 위치·같은 자세에서 **0 mm 접촉과 3 mm 공중을 구분할 수 있는지** 살피는 첫 단계입니다. 자기장 차이와 위치 간 겹침, 배경 변화, iPad 이동 여부를 먼저 확인합니다. 시점·배치가 다른 접촉 자료와 비교하므로 높이 효과와 배치 간 변화가 섞일 수 있습니다. 이전 접촉 2회차의 행 경계 문제도 별도로 취급합니다.

현재 A/B 모델은 0 mm 접촉 위치 추정용이며 접촉 분류기가 아닙니다. 앱은 수집 조건과 모델의 높이·접촉 조건이 다르면 이를 표시합니다. 기존 모델이 3 mm에서 점을 표시하거나 숨기는 것을 접촉 판정 결과로 해석하지 않습니다.

높이별 자료를 기존 위치 모델에 자동으로 합치지 않습니다. 첫 분석 결과를 보고 높이 조건별 위치 모델과 접촉 분류의 구성을 결정합니다. 0/3 mm 두 조건만으로 1 mm, 2 mm 또는 임의 자세의 접촉 판정을 검증했다고 주장할 수 없습니다. 독립 반복 수집 전에는 이번 자료의 분리 가능성과 재생 결과를 일반화 성능과 구분합니다.
