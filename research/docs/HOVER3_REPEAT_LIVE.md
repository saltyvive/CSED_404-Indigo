# 공중 1/2/1+2 · 통합 A/B/C 실시간 비교 · 1.24.0(29)

2026-11-25 공중 2회차를 가져와 기존 모델로 먼저 평가한 뒤 새 모델을 추가했습니다. **통합 모드: 접촉 1+3 고정 × 공중 1/2/1+2 × A/B/C**, **3 mm 전용: 공중 1/2/1+2 × A/B**를 선택할 수 있습니다. 기존 접촉 7개 조합의 A/B도 유지합니다. [전체 평가와 배경 변화 분석](../evaluation/HOVER3_PASS2_RESULTS.md).

## 접촉·공중을 함께 시험

1. **A/B/C 실시간 테스트 → 통합 · 0 / 3 mm**를 선택합니다. 이번 배포는 이 모드의 **공중 1+2 · A**로 열립니다.
2. **3 mm 학습 회차**에서 `1 · 기존`, `2 · 단독`, `1+2 · 추가 학습` 중 선택합니다. 어느 것을 골라도 접촉 학습 자료는 1+3회차입니다. 다음 줄에서 A/B/C를 선택합니다.
3. iPad·종이·스탠드 배치를 유지하고 펜과 이동 홀더를 멀리 두어 **준비 3초 + 배경 10초**를 측정합니다. 같은 수평 위치에서 높이를 0→3→0 mm로 바꿔 청록색(접촉), 보라색(공중), 주황색(보류)을 비교합니다.
4. 통합 모드 안에서 공중 회차 조합을 바꾸면 **같은 배경을 유지**하고 궤적과 로그 구간을 새로 시작합니다. A/B/C 전환은 지도에 표시할 모델만 바꿉니다. 선택한 회차 조합의 A/B/C는 같은 자력계 입력으로 함께 계산·기록합니다.

총 9개 조합을 선택할 수 있지만, 다른 회차 조합 9개 모두를 같은 프레임에 계산하는 기능은 아닙니다. 같은 배경에서 회차 조합을 바꿔 개인 시험하고, 기록된 정답점의 정량 비교는 같은 입력으로 이미 수행한 평가표를 사용합니다. 센서가 없는 시뮬레이터에서는 화면/선택만 확인합니다.

## 3 mm 전용 위치 시험

**테스트 모드 → 3 mm · 공중 → 학습 회차 1 / 2 / 1+2 → A / B**를 선택합니다. 펜촉 높이를 3 mm로 맞춘 상태의 XY 추정이며 이 모드에서는 접촉 여부를 분류하지 않습니다. C는 두 높이를 함께 학습하는 모델이므로 통합 모드에 있습니다.

단일 높이 안에서는 회차 조합을 바꿔도 배경을 유지합니다. 통합↔단일 높이처럼 테스트 모드를 바꾸면 배경을 다시 맞춥니다. iPad가 움직이거나 센서가 끊긴 경우에도 다시 맞춥니다.

평가 카드에는 공중 1 모델의 **2회차 평가**, 공중 2 모델의 **1회차 평가**를 보여줍니다. 공중 1+2는 두 회차를 모두 학습했으므로 별도 시험 회차가 없다고 표시합니다. 학습 자료 재생 수치는 접어 둔 항목에서 확인할 수 있습니다. 2→1 평가는 사후 역방향 비교입니다.
