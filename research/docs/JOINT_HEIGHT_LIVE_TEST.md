# 접촉·공중 통합 실시간 시험 · 1.21.0(26)

2026-11-25 사용자 요청: **0 mm는 1+3회차, 3 mm는 1회차**를 함께 사용해 위치와 접촉/비접촉 후보를 표시합니다. 0 mm의 2회차는 이 모드에 포함하지 않습니다. 기존 단일 높이 A/B와 0 mm의 7개 조합은 유지합니다.

## 사용법

1. **A/B 실시간 테스트 → 통합 · 0 / 3 mm**를 선택합니다. 이번 설치는 이 모드의 A로 시작합니다.
2. iPad·도면·스탠드·케이블 배치를 유지하고 φ=0°·θ=90°·α=0°로 맞춥니다.
3. 펜과 이동 홀더를 멀리 옮기고 **배경 맞추기**를 누릅니다. 준비 3초 + 배경 10초입니다.
4. 스윗 스팟의 같은 점에서 **0 → 3 → 0 mm**로 바꾸며 색과 추정 좌표를 확인합니다. 중앙과 네 모서리에서 반복하면 구분되는 영역과 어려운 영역을 비교하기 쉽습니다.
5. A/B를 바꾸어 같은 방식으로 확인합니다. A/B와 두 높이는 동일한 배경·자력계 입력으로 함께 계산되므로 높이를 바꿀 때마다 배경을 다시 맞추지 않습니다. 앱의 통합/단일 높이 모드를 전환하면 배경을 다시 맞춥니다.

- **청록색:** 접촉(0 mm) 추정.
- **보라색:** 공중(3 mm) 추정.
- **주황색 테두리:** 위치 또는 높이 구분이 불확실해 판정 보류. 후보 위치는 참고용입니다.
- 신호가 약하면 후보도 숨깁니다. 궤적은 최근 8초이며 판정 보류·수신 공백·접촉 상태 변경 때 연결을 끊습니다.

색은 실제 접촉 센서의 측정값이 아닙니다. 중간 높이, 3 mm보다 높은 위치, 다른 자세는 검증하지 않았습니다. 오른쪽 위 오차의 원인도 추가 수집 전에는 확정하지 않습니다.

## 추정 방식

기존 고정 모델 `model_A_13` / `model_B_13`, `model_A_hover3_1` / `model_B_hover3_1`의 바이트를 그대로 사용합니다. 서로 다른 높이의 데이터를 기존 단일 높이 학습기에 합쳐 좌표를 평균내지 않고, **각 높이 모델에서 전체 XY를 독립적으로 검색한 뒤 잔차를 비교**합니다.

입력은 현재 0.12초 인과적 3축 중앙값에서 실시간 배경을 뺀 자기장 벡터뿐입니다. 정답 좌표·높이·장치 자세·안내선·이동 시간은 추정에 넣지 않습니다. A는 각 높이의 보간 표면까지의 최소 잔차, B는 각 높이의 최근접 학습 패턴 잔차를 비교합니다. 작은 잔차 쪽의 XY를 후보로 사용합니다.

두 잔차 차이가 **0.75 µT 이하**면 높이 판정을 보류합니다. 이 수치는 재생 전에 정한 시험 기준이며 기존 위치 모호성 기준과 같은 값입니다. 최적화하거나 확률로 보정한 값이 아닙니다. 승리 후보가 기존 신호 세기·잔차·다른 위치와의 모호성 기준을 통과해야 색을 채웁니다. 위치와 높이의 기존/새 보류 사유는 로그에서 분리됩니다.

B는 접촉이 위치당 8패턴, 공중이 4패턴이므로 최근접 잔차가 접촉 쪽에 유리해질 수 있습니다. A/B 잔차도 서로 같은 척도의 정확도나 확률이 아닙니다. 이 구현은 요청한 통합 시험용 기준 모델이며 최종 접촉 분류기를 선정한 것은 아닙니다.

## 기존 학습 자료 재생 · 독립 검증 아님

실제 앱과 같은 Swift 추정기로 접촉 546배치, 공중 273배치의 정지점 대표값을 재생했습니다. 각 입력은 정지 구간 앞 0.4초/뒤 0.2초를 제외한 중앙값에서 해당 행의 **시작 배경만** 뺀 값입니다. 실시간 0.12초 프레임 성능 또는 자유 이동 정확도를 뜻하지 않습니다. 모든 배치가 모델 학습에도 사용됐습니다.

## 기록과 재현

`training_combination=joint_contact13_air1`로 기록합니다. 기존 XY 열은 A의 선택 후보, `knn_` XY는 B의 선택 후보입니다. `joint_a_*`, `joint_b_*` 열에는 최종 `estimated_state`(contact/air/uncertain), 최근접 높이 후보, 잔차 차이, 높이 모호성, **두 높이 각각의 XY·잔차·위치 표시 통과·위치 모호성**을 남깁니다. 통합 모드의 단일 학습 높이/접촉/배치 열은 빈 값입니다.

각 로그 옆에 네 모델 사본과 해시·두 학습 조건·임계값·실시간 배경 샘플을 저장합니다. `contactDetectionAvailable=true`는 시험용 추정이 있다는 뜻이며 `measuredContactAvailable=false`로 실측과 구분합니다. 자유 이동에는 시각별 접촉 정답이 없어 로그만으로 분류 정확도를 계산하지 않습니다.
