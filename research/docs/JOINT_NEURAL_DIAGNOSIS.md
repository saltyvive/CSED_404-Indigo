# C의 접촉 오판 진단 · 2026-11-25

공중 반복 수집 부족도 미해결 문제지만, **자료 수만 늘리면 해결된다는 근거는 없습니다.** 고정된 C에 같은 원본을 넣고 배경 처리만 바꿔 보니 공중의 접촉 오판이 58/273에서 5/273으로 줄었습니다. 학습과 실시간 사이의 배경 처리 차이에 C가 취약하다는 직접적인 진단입니다. 다만 종료 배경을 사용한 학습 자료 재생이므로 이를 실시간 개선 성능으로 주장하지 않습니다. 보정 후에도 새로운 행에서는 상당한 오판이 남습니다.

이 분석은 사용자 실시간 경험의 원인을 찾기 위한 **사후 진단**입니다. 해당 실시간 시험 자체의 정답 위치/높이 기록은 없으므로 그 순간의 원인을 특정하지는 못합니다. 공중 2회차 준비를 먼저 완료했고, 기존 C의 가중치·표시 임계값을 변경하거나 새 2회차 자료를 사용하지 않았습니다.

## C가 학습한 방식

실제 구현은 [학습기](../scripts/train_joint_mlp.py)와 [Swift 추정기](../MagAir/Core/JointNeuralModel.swift)에 있습니다. **3 → 64 → 64 → 3 완전연결 MLP**, 학습 파라미터 **4,611개**입니다. 입력은 배경을 뺀 Bx·By·Bz를 학습 평균/표준편차로 정규화한 값입니다. 두 은닉층은 tanh, 출력은 x·y와 접촉 점수입니다. 접촉 출력에 sigmoid를 적용하며 두 작업이 같은 은닉층을 학습합니다. 높이별 모델 두 개를 돌려 승자를 고르는 구조가 아닙니다.

- 접촉 0 mm **1+3회차 546번**과 공중 3 mm **1회차 273번**, 총 819번의 펜 배치를 사용했습니다. 접촉 2회차는 포함하지 않았습니다.
- 정지 구간 중앙값과 0.12초 인과적 필터로 만든 짧은 구간 3개, 배치당 4개 대표값을 사용합니다. 총 3,276벡터는 독립 측정 3,276번이 아닙니다.
- 학습값은 각 행 시작·종료 배경 사이의 선형 보간으로 보정합니다. 실시간에는 미래 종료 배경이 없으므로 사용자가 먼저 잰 배경만 뺍니다. 주 재생 평가도 그 행의 시작 배경만 사용합니다.
- 손실은 `0.5 × 위치 제곱오차 합 + 0.2 × 접촉 이진 교차엔트로피`에 L2 규제를 더합니다. 위치 오차는 x·y 모두 25 mm 단위입니다. 접촉과 공중의 전체 가중치는 각각 50%여서 접촉 표본이 두 배라는 이유만으로 학습 손실이 두 배가 되지는 않습니다.
- full-batch Adam 2,000회, 학습률 0.003→0.0003, seed 20261125입니다. 5개 행 분할 평가 후 모든 819배치를 학습한 최종 C를 배포했습니다. 구조·손실 비율의 탐색은 하지 않았습니다.
- 입력에 목표 XY, 장치 φ·θ·α, 높이, 행/열, Pencil IMU는 들어가지 않습니다. iPad IMU는 움직임 검사 등에 사용하고 이 신경망의 추정 입력으로 사용하지 않습니다.

접촉 점수 ≥0.65는 접촉, ≤0.35는 공중, 그 사이는 보류입니다. 학습 자기장에서 너무 멀거나 출력 XY가 범위를 크게 벗어나도 보류합니다. 가장 가까운 자기장까지의 거리는 보류용이며, C의 좌표/높이를 최근접값으로 정하지 않습니다. 이 점수는 보정된 정확도 확률이 아닙니다.

## A/B보다 오판이 많은 이유: 표시율 차이와 실제 오판을 함께 봐야 함

아래는 **같은 공중 273번, 같은 3축 입력, 시작 배경만 사용한 학습 자료 재생**입니다. 독립 시험 정확도가 아닙니다. 정상 색을 표시한 수는 정답과 오판의 합입니다.

| 모델 | 올바른 공중 | 접촉 오판 | 보류 | 색을 표시한 수 | 표시 중 오판 비율 |
|---|---:|---:|---:|---:|---:|
| A | 105 | 27 | 141 | 132 | 20.5% |
| B | 83 | 10 | 180 | 93 | 10.8% |
| C | 174 | 58 | 41 | 232 | 25.0% |

A/B는 두 높이 모델의 잔차 차이가 0.75 µT 이하이면 보류합니다. 공중의 보류 중 A는 132/141개, B는 176/180개가 이 높이 모호성 조건에 해당합니다. 따라서 사용자가 보는 잦은 보류는 단순히 ‘학습 벡터가 없어서’만이 아니라 **두 높이 모두 비슷하게 설명하는 신호** 때문인 경우가 많습니다. 나머지는 위치 추정 측의 거부입니다.

C는 높이 잔차 차이를 검사하지 않고 신경망 점수로 결정하므로 표시 수가 많고, 그만큼 맞는 표시와 틀린 표시가 함께 늘었습니다. 그러나 표시율 차이만으로 설명이 끝나지도 않습니다. 사후에 C의 구간을 0.05/0.95로 엄격하게 해도 **공중 133개 표시 중 정답 95·오판 38**입니다. A의 132개 표시 중 정답 105·오판 27과 비교하면 단순 임계값 강화만으로 이번 문제를 해결하지 못합니다. 이 비교는 전체 개수만 비슷하고 선택된 점은 다르며, 임계값을 평가 자료로 살펴본 진단일 뿐 배포/공정한 독립 성능 비교가 아닙니다.

기본 C 공중 오판 58개 중 **45개가 접촉 점수 0.9 이상, 38개가 0.95 이상**입니다. 높은 점수를 실제 정확도 확률로 읽으면 안 되는 이유입니다. 위치 오차 중앙값도 A 0.667 / B 0.378 / C 1.523 mm로, 이번 학습 자료 재생에서 C가 더 정밀하지 않았습니다. B는 보관한 자기장 패턴에 직접 맞추는 방식이라 자기 자료 재생에서 특히 유리할 수 있습니다.

## 배경 처리만 바꾼 진단

C 가중치·임계값·정답은 그대로 두고, 입력만 (1) 시작 배경 차감과 (2) 시작·종료 배경 선형 보정으로 바꿨습니다. 후자는 학습 때 사용한 입력의 재생이며 미래 배경을 이용합니다. 선형 보정이 실제 순간의 배경을 정확하게 복원했다는 보장도 없습니다.

| 공중 273점 · 고정 C | 올바른 공중 | 접촉 오판 | 보류 | 후보 XY 중앙 / P95 mm |
|---|---:|---:|---:|---|
| 시작 배경만 차감 | 174 | **58** | 41 | 1.523 / 4.175 |
| 종료 배경까지 선형 보정 | 202 | **5** | 66 | 1.040 / 3.325 |

보류 증가도 있으므로 ‘53개의 오판이 전부 정답으로 바뀌었다’는 뜻은 아닙니다. 두 입력 처리 사이 공중 벡터 차이는 중앙 **0.701 µT**, P95 **3.517 µT**입니다. 112/273점의 표시 상태가 달라졌습니다. 입력 편향이 접촉 결정 경계를 넘어가도 학습 벡터와의 거리 검사에는 통과해 자신 있게 잘못 분류할 수 있습니다.

특히 첫 행은 시작–종료 배경 차이가 **7.759 µT**였습니다. 시작 배경만 사용하면 21개 중 정답 0·접촉 오판 13·보류 8, 종료 배경 보정 시 정답 19·오판 0·보류 2입니다. 중앙 위치 오차도 2.801→0.896 mm였습니다. 온도·센서 편향·물체·홀더 복귀 위치 등 어느 원인으로 배경이 달라졌는지는 확정할 수 없습니다. 이 결과만으로 펜촉을 잘못 놓았다고 판단하지 않습니다.

기본 C의 공중 보류 41개는 학습 자기장 범위 이탈 8개와 중간 접촉 점수 33개였습니다. 약한 신호/XY 범위로 인한 공중 보류는 없었습니다. 배경 보정 후에는 66개 모두 중간 점수 때문입니다. 즉 배경 차이를 줄여도 두 높이 경계가 불확실한 문제는 남습니다.

## 자료 부족인가, 모델 문제인가

**확인한 사실**은 다음과 같습니다.

- 배경 처리 차이에 대한 취약성이 큽니다. 같은 자료에서 입력 보정만 바꾸는 위 비교가 직접적인 근거입니다. A/B 학습에도 종료 배경 보정이 있으므로 C만의 전처리 문제는 아니지만, 각 모델이 입력 변화에 반응하는 방식과 보류 기준은 다릅니다.
- 종료 배경 보정을 해도 **학습하지 않은 행**의 C 평가에서 공중 273점 중 정답 160·오판 47·보류 66입니다. 같은 조건의 학습 자료 재생(정답 202·오판 5·보류 66)과 차이가 큽니다. 기존 시작 배경 행 평가의 정답 154·오판 64·보류 55보다 일부 개선되지만 일반화 문제까지 사라지지는 않습니다. 이는 같은 캠페인의 행 분리 시험이며 독립 반복 검증은 아닙니다.
- 기존 [높이 비교](../evaluation/HOVER3_PASS1_RESULTS.md)에서는 접촉 1↔3회차의 같은 점 자기장 차이 중앙값 2.828 µT가 접촉↔공중 차이 1.842 µT보다 컸습니다. 다른 XY·높이끼리도 신호가 가깝습니다. 관측 분포가 겹친다는 근거이지, 모든 상황에서 구분이 불가능하다는 증명은 아닙니다.
- 공중은 한 회차뿐이라 회차 변화의 범위를 배우거나 독립 재현성을 확인할 자료가 부족합니다. 3,276개의 대표벡터 수가 이 한계를 해결하지 않습니다. 높이와 수집 시점/캠페인도 얽혀 있습니다.

**아직 가설인 부분**도 구분해야 합니다. 매끈한 MLP가 국소적으로 복잡한 자기장-위치 관계를 충분히 표현하지 못할 가능성, XY와 접촉을 함께 최적화할 때의 간섭, 손실 비율·규제·학습량의 영향은 있습니다. 하지만 구조나 손실을 바꾼 대조 실험을 하지 않았으므로 특정 원인으로 단정할 수 없습니다. 학습 자료 자체에서도 접촉/공중 중간 점수가 남는다는 이유만으로 ‘신경망을 더 크게 하면 된다’고 결론내리지 않습니다.

## 다음 판단 순서

1. 준비한 **3 mm 2회차**를 현재 고정된 A/B/C로 먼저 평가합니다. 지금 수집은 올바른 공중 판정의 반복 재현성을 확인하고 학습 범위를 늘리는 데 의미가 있습니다. 공중만 새로 재므로 새로운 접촉 오판율이나 높이/캠페인 혼동을 완전히 검증할 수는 없습니다.
2. 기존 모델 평가를 기록한 뒤 공중 1+2회차를 사용한 새 모델을 비교합니다. 변경한 모델의 자기 자료 재생 개선과 아직 보지 않은 회차 개선을 구분합니다.
3. 다음 개선 우선순위는 **실시간에 가능한 배경 관리와 그 잔여 변화에 대한 학습**입니다. 펜을 확실히 멀리 둔 때만 배경을 갱신하는 방법, 측정에서 확인한 배경 변화 범위의 입력 편향을 같은 정답에 추가하는 방법 등을 별도 모델로 시험할 수 있습니다. 시작 배경만 사용하도록 학습을 단순 변경하면 행/시간에 묶인 편향을 외울 수도 있으므로 그것만으로 해결됐다고 보지 않습니다. 펜이 스윗 스팟에 있는 동안 자기장 변화를 배경으로 흡수해서도 안 됩니다.
4. 그다음 구조/손실 비율 비교나 위치·접촉 출력 구성 변경을 검토합니다. 소수 위치에서 0→3→0 mm를 교대로 재는 실험은 시간/배경 영향과 높이 효과를 구분하는 추가 선택지입니다. 현재 요청한 273점 수집을 바꾸거나 당장 추가 의무로 만들지는 않았습니다.

## 재현과 검사

`research/`에서 기존 [C 학습·재생 재현 절차](JOINT_NEURAL_MODEL.md)와 [A/B 동일 입력 재생 절차](JOINT_HEIGHT_LIVE_TEST.md)를 먼저 수행합니다. 기본 경로는 해당 문서의 실제 실행 폴더명이며 다른 출력 폴더를 썼으면 아래 인자를 바꿉니다.

```sh
build/joint-mlp-venv/bin/python scripts/diagnose_joint_mlp.py \
  --source reports/hover3-20261125-pass1 \
  --trained reports/joint-mlp-20261125-v1 \
  --ab build/tests/joint-height-replay.json \
  --out reports/joint-mlp-diagnosis-new-run
```

[진단 코드](../scripts/diagnose_joint_mlp.py)는 모델과 앱 번들의 바이트 일치, 기존 C 예측 재현, A/B와 C의 동일 trial·좌표·3축 입력, 행 분리 모델의 평가 trial 비포함, 거부 이유 개수 합계를 검사합니다. 생성 결과는 덮어쓰지 않습니다. 모델/관측/기존 예측 파일 해시, 행별 배경 변화·오차, 오프라인 보정 예측 및 임계값별 진단을 로컬 `reports/`에 저장하고 핵심 결과·절차를 이 문서에 보존합니다. 앱 모델과 원본 ZIP은 변경하지 않습니다.
