# 첫 회차 273점 실시간 시험 · 2026-11-23

사용자가 1회차 13행을 마친 뒤 먼저 실시간으로 시험하기를 요청했습니다. 앱 **1.14.0(16)**에는 그 자료의 **273개 위치를 모두 사용한 임시 지도**를 넣었습니다. 첫 화면은 **격자 내부 테스트**이며, 기존 13묶음 완료 이력과 원본 파일은 유지합니다. 2·3회차 수집은 그대로 이어갈 수 있습니다.

## 사용 방법

1. iPad·스탠드·종이·케이블을 수집 때와 같은 배치로 둡니다. 이번 모델 조건은 **φ=0°·θ=90°·높이 0 mm·표면 접촉**입니다. 수집 중 iPad 화면 경사는 약 **52.2–52.4°**였습니다.
2. 펜슬과 함께 움직이는 홀더를 수집 때 배경을 재던 먼 위치로 치웁니다. **펜·홀더를 멀리 두었음 → 배경 맞추기**를 누르고 준비 3초 + 배경 10초 동안 기다립니다.
3. 펜 끝을 종이에 내려놓고 중앙·테두리·내부를 천천히 움직입니다. 안내선 메뉴에서 13개 가로선, 21개 세로선, 두 대각선을 선택할 수 있습니다. 안내선은 표시용이며 추정 위치를 그 선에 붙이지 않습니다.
4. 청록색은 표시 기준을 통과한 추정점, 주황색 테두리는 불확실한 후보입니다. 약한 신호에서는 점을 숨깁니다. 최근 8초의 청록색 위치만 궤적으로 연결합니다. 펜을 들어 옮긴 뒤에는 궤적을 지우세요. 접촉 상태를 자동 판별하는 모델은 아닙니다.
5. 약 1분마다 배경을 다시 맞추는 것을 권장하지만, 1분 경과만으로 점 표시를 중단하지 않습니다. iPad가 움직이거나 센서 수신이 끊기면 배경을 다시 측정합니다.

위치 표시는 왼쪽 위 원점의 도면 기준 추정 mm이며, mm 단위의 정확도를 보증하지 않습니다. 자유 테스트 기록은 `Documents/MagAirGridLiveTests`에 자동 저장됩니다. 불안정한 위치를 확인할 때에는 해당 행·열 번호도 함께 알려주면 좋습니다.

## 자료 확인과 모델 구성

- 완료된 13세션, 정지점 273개, 행별 배경 26개를 확인했습니다. 재측정으로 제외된 시도 7개는 학습에 넣지 않았습니다. 91개 원본 파일의 해시와 CSV 행 수를 로컬 보고서에 기록했고, 센서 행 수가 각 manifest와 일치했습니다.
- φ·θ·높이·접촉·배치 번호가 13묶음에서 일치합니다. 이전 5×5·9×9 데이터나 다른 배치는 섞지 않았습니다.
- 각 정지 구간의 앞 0.4초와 뒤 0.2초를 빼고 3축 중앙값을 구합니다. 각 행의 앞뒤 배경 중앙값을 시간에 따라 선형 보간해 빼줍니다. 정지 구간 자기장 산포는 약 0.55–0.73 µT였습니다.
- 21×13 위치에 자기장 벡터를 놓고, 점 사이는 쌍선형 보간합니다. 실시간에는 새 배경을 뺀 3축 자기장을 약 0.12초 동안 인과적으로 중앙값 필터링하고, 지도 전체에서 가장 비슷한 위치를 탐색합니다. 181×181 검색 후보에는 모든 원래 격자점이 포함됩니다. 검색 간격은 센서 정확도가 아닙니다.
- φ·θ·높이와 iPad 경사는 조건/출처 기록입니다. 이 모델에 Pencil IMU, 장치 좌표, 안내 경로, 실제 펜 속도 또는 참 좌표를 추론 입력으로 제공하지 않습니다.

## 보존한 품질 주의점

1행의 앞뒤 배경 변화는 약 **5.88 µT**로 다른 행보다 큽니다. 선형 배경 보정은 오프라인 가정이며, 그 변화가 선형이었다거나 주변 환경·장치 배치가 완전히 같았음을 증명하지 않습니다.

앱의 경고 목록뿐 아니라 연속 `device_motion.csv`도 확인했습니다. **1·2·10·11·12행**의 이동/준비 구간에서 짧은 움직임 임계값 초과가 있었으며 완료된 실제 정지 측정 구간에서는 없었습니다. 11행의 경고는 6열 준비 시간에 있었고 정지 측정 전에 끝났습니다. 이 행들을 임시 시험에 포함한 검토 사유와 원래 경고·시각·센서 크기를 보고서와 모델에 보존했습니다. 작은 중력각 변화만으로 평행이동·방위각 변화가 없었다고 단정할 수는 없습니다.

273점 모두가 학습점이므로 자기 자신을 잘 재구성하는 것은 독립 정확도 평가가 아닙니다. 학습 자료의 시작 배경만 사용한 819구간 재생도 동일 자료를 재사용한 진단입니다. **한 번씩만 놓았기 때문에 재배치 반복성은 아직 알 수 없으며, 독립 검증 결과도 없습니다.** 현재 목적은 실제 손 움직임을 새 모델이 얼마나 따라오는지 빠르게 확인하는 것입니다.

## 재현과 검증

`research/`에서 실행합니다. 원본과 생성 보고서는 Git에서 제외합니다. 같은 이름의 보고서 폴더는 덮어쓰지 않으므로 재실행 시 새 출력 경로를 사용합니다.

```sh
python3 scripts/build_printed_grid_model.py \
  data/printed-grid-20261123-pass1/MagAir-*/ \
  --out reports/printed-grid-pass1-new-run --passes 1 \
  --allow-reviewed-transient-motion \
  --review-note 'Reviewed transient iPad motion outside completed steady intervals for provisional personal testing; physical geometry change cannot be ruled out.'
```

검토 옵션은 실제 측정 중 움직임을 허용하지 않습니다. 해당 구간에 움직임이 있으면 모델 생성을 중단합니다. 누락 행·중복 세션·잘못된 좌표/자세 라벨·다른 배치·센서 공백·불안정한 정지/배경도 거부합니다. 여러 회차를 사용할 때에는 각 선택 회차의 13묶음 전체를 명시해야 하며, 위치별로 회차에 같은 가중치를 둡니다.
