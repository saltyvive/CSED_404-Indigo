# 3 mm 공중 2회차 · 1.23.0(28)

2026-11-25 사용자 요청으로 같은 3 mm 배치를 2회차까지 연장했습니다. φ=0°·θ=90°·α=0°·펜촉 높이 3 mm를 유지합니다. 기존 1회차 원본과 모델은 그대로 두고 새 회차를 먼저 평가한 뒤 학습에 사용합니다.

## 수집 순서

1. **273점 수집 → 배치 확인하고 준비 완료**에서 높이·각도·종이·iPad 고정을 확인합니다. 처음에는 **13/26행 저장, 14/26 · 2회차 · 1행**으로 표시됩니다.
2. 펜과 이동 홀더를 기존의 먼 배경 측정 위치에 두고 시작 배경을 측정합니다. **준비 3초 + 배경 10초**입니다.
3. **1행 오른쪽 끝 21열**에서 시작합니다. 1행은 21→1열, 2행은 1→21열이며 방향을 번갈아 **1→13행**으로 내려갑니다. 홀수 행은 오른쪽부터, 짝수 행은 왼쪽부터입니다.
4. 각 점은 **준비 3초 + 정지 2초**이며 행 안 자동 진행과 안내음이 켜져 있습니다. 정지 측정 중 높이 3 mm를 유지하고 펜촉의 수직 투영점을 표식에 맞춥니다. 늦게 도착하거나 자세가 흐트러지면 일시정지/재측정을 사용합니다.
5. 각 행의 21점 후 펜과 홀더를 같은 먼 위치로 옮겨 종료 배경 10초를 측정합니다. 행 저장 완료를 확인하고 다음 행으로 이동합니다. **26/26행 저장**이면 공중 1·2회차가 모두 완료된 상태입니다.

새 수집은 273점·13행입니다. 모델의 접촉/공중 판정에 맞춰 높이를 바꾸지 않습니다. 정답은 사람이 맞춘 장치의 **3 mm**이며 추정 결과와 독립적입니다. 펜·홀더를 멀리 둔 배경에는 공중 정답을 부여하지 않습니다.

## 보존과 평가

- 공중 캠페인 `SweetSpot-FB8B1625-27C7-4190-B577-128C7EE38D04`를 유지합니다. `plannedPasses=2`, `ascendingPasses=[2]`, `extensionID=hover3_pass2_ascending_20261125_v1`로 확장하며, 이전·새 캠페인 JSON을 먼저 별도 보존합니다. 과거 manifest의 `plannedPasses=1`과 행 순서는 수정하지 않습니다.
- 명시적 실행 인자 `--prepare-hover3-pass2`로 준비합니다. 이미 확장한 배치를 다시 실행해도 ID·기존 완료 기록을 초기화하지 않습니다. 시작 배경이나 점 측정은 자동으로 시작하지 않습니다.
- 새 2회차 manifest에 공중 A1/B1 평가 해시와 `evaluationJointModelSHA256`의 **A_contact13 / B_contact13 / A_air1 / B_air1 / C_joint** 다섯 해시를 남깁니다. 조건이 다른 접촉 1회차 모델을 공중 2회차 평가 모델로 선택하지 않도록 캠페인·자세를 확인합니다.
- [고정 평가 계획](../evaluation/hover3_pass2_plan.json)에 따라 새 자료를 먼저 평가합니다. **공중 전용 A/B의 XY**, **통합 A/B/C의 XY·높이·보류**를 동일한 완료 측정에 비교합니다. 시작 배경만 사용하는 주 평가와 종료 배경을 사용하는 오프라인 진단을 구분합니다.
- 공중 정답/접촉 오판/보류 수와 분모, 후보 XY 중앙·P95·RMSE, 올바른 공중 판정과 위치 오차 2.5/5 mm를 동시에 만족한 비율을 기록합니다. 이번 자료는 공중만 있으므로 새 접촉 자료에 대한 오판율·정밀도·균형 정확도는 계산할 수 없습니다.
- 아직 평가나 추가 학습을 완료한 것이 아닙니다. 이번 설치에서 기존 A/B/C 가중치와 표시 기준은 바꾸지 않았습니다. 새 원본은 수집 완료 후 기존 절차대로 불변 ZIP·SHA-256 목록으로 보존합니다.
