# 높이별 A/B 실시간 테스트 · 1.20.0(25)

이 문서는 1.20 도입 당시 기록입니다. 1.21에는 [0/3 mm 통합 접촉·공중 시험](JOINT_HEIGHT_LIVE_TEST.md)을 추가했으며, 아래 단일 높이 모드는 그대로 유지합니다.

2026-11-25 사용자 요청으로 3 mm 첫 회차의 고정 A/B 모델을 앱에 적용합니다. **3 mm로 높이를 유지한 위치 추정 시험**입니다. 현재 펜이 접촉했는지 또는 몇 mm 떠 있는지 자동 판정하는 기능은 없습니다.

## 사용

1. 앱의 **A/B 실시간 테스트** 탭에서 **3 mm · 공중**을 선택합니다. 이번 배포는 이 조건의 **1회차·A 모델**로 열립니다.
2. φ=0°·θ=90°·α=0°와 수집 당시 iPad·종이·스탠드·케이블 배치를 유지합니다.
3. 펜과 이동 홀더를 배경 측정 때의 먼 위치로 옮겨 **배경 맞추기**를 누릅니다. 준비 3초 + 배경 10초입니다.
4. 펜촉을 인쇄점의 수직 위 **3 mm**에 놓고 점·가로선·세로선·대각선을 따라 움직입니다. A/B 선택은 표시할 결과만 바꾸며 두 모델은 같은 센서 입력으로 함께 계산합니다.
5. 같은 높이에서 A/B를 바꿀 때는 배경을 다시 측정하지 않아도 됩니다. **0 mm · 접촉**으로 조건을 바꾸면 배경이 초기화되므로 장치 높이를 직접 맞춘 뒤 배경부터 다시 측정합니다. 0 mm에는 기존 7조합·14개 모델이 그대로 있습니다.

청록색은 표시 기준을 통과한 추정점이고, 주황색은 불확실한 후보입니다. 점이 표시됐다는 사실이 접촉 또는 높이 3 mm 검출을 뜻하지 않습니다. 자유 이동 로그에는 펜촉 정답 좌표가 없으며 자동 정확도 평가 자료로 취급하지 않습니다.

## 모델과 화면

- `model_A_hover3_1.json` / `model_B_hover3_1.json`은 [평가 기록의 고정 모델](../evaluation/HOVER3_PASS1_RESULTS.md)과 바이트 단위로 같습니다. 새로운 학습이나 임계값 조정은 하지 않았습니다.
- `hover3_model_catalog.json`에는 첫 회차의 **학습 자료 재생** 지표만 기록합니다. 별도 공중 반복 검증이 없다는 안내를 표시합니다. 기존 `model_catalog.json`과 14개 접촉 모델은 바꾸지 않았습니다.
- 마지막 모델 선택은 앱 설정에 저장합니다. 실행 인자 `--live-hover3`는 3 mm 모델과 실시간 탭을 선택할 뿐, 수집 배치·완료 행·원본을 변경하거나 배경 측정을 자동 시작하지 않습니다.
- 높이 조건을 바꾸면 이전 궤적·추정값·배경을 비우고 로그를 마감합니다. 같은 접촉 조건의 회차 조합 변경은 기존처럼 배경과 필터를 유지합니다.

## 기록과 재현

기존 `Documents/MagAirGridLiveTests/`의 CSV·모델 사본·메타데이터·종료 기록 형식을 유지합니다. 새 CSV의 `model_training_condition`, `model_tip_height_mm`, `model_tip_state`, `model_campaign_id`는 **선택한 모델의 학습 라벨**이며 현재 펜의 측정/추정 상태가 아닙니다. 메타데이터에도 `modelTrainingContext`, `contactDetectionAvailable=false`와 A/B 모델 해시를 남깁니다. `training_combination=hover3_1`이 새 3 mm 모델입니다.

`research/`에서 번들을 재생성합니다. 분석 보고서가 없다면 [첫 회차 분석 재현 절차](../evaluation/HOVER3_PASS1_RESULTS.md)를 먼저 실행합니다.

```sh
python3 scripts/bundle_hover3_models.py reports/hover3-20261125-pass1
python3 scripts/make_project.py
```

번들러는 고정 모델과 분석 모델의 일치, 높이 라벨, 평가 범위를 검사합니다. `build/tests/hover3-model-parity.json`은 실제 분석 입력과 Python 예측으로 생성한 Swift 대조 자료입니다. 모델 라이브러리 검사는 기존 924개와 새 1,092개의 **총 2,016개 예측**에서 좌표·잔차·표시·모호성 판정이 일치함을 확인했습니다. 잘못된 해시·높이·독립 평가 표기와 조건 간 배경 재사용도 검사했습니다.

기존 수집 배치의 13행 완료 상태를 유지하며 추가 수집은 시작하지 않습니다. 현재 결과는 [3 mm 1회차 분석](../evaluation/HOVER3_PASS1_RESULTS.md)의 품질·반복 검증 한계를 따릅니다.

## 설치 확인 · 2026-11-25

실기기·시뮬레이터 빌드에 성공했습니다. 시뮬레이터에서 3 mm A/B, 학습 재생 지표, 0 mm의 7개 조합과 1+3 선택을 확인했습니다. iPad 설치·실행 후 설정을 다시 읽어 `hover3_1` 선택을 확인했으며, 기존 수집 배치 설정 바이트와 원본 483개 파일의 경로·크기·수정 시각은 설치 전후 동일했습니다. 실제 펜 이동에 대한 성능은 사용자의 실기기 시험으로 확인해야 합니다.
